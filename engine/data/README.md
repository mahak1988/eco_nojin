# Engine Sample Data

This directory contains sample data files used for testing and demonstration purposes within the `engine` modules.

## Contents

- `dem_sample.tif`: A sample Digital Elevation Model (DEM) file in GeoTIFF format.
- `sample_dem.asc`: A sample DEM file in ASCII Grid format.

## Source

These files are typically synthetic or freely available public domain data used for internal testing.

## Usage

These files are referenced by certain analysis modules within `engine/land` for testing their functionality without requiring large, real-world datasets.
