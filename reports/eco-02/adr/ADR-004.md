# ADR-004: Service Consolidation to Bounded Contexts

## Status
Accepted

## Context
The `services/` directory contains 73 microservice directories, 63% of which are infrastructure services. This granularity is excessive and creates operational complexity.

## Decision
Consolidate 73 services into 8 bounded-context modules:
1. Platform Core (25 infra services)
2. Meteorology (8 services)
3. Hydrology (6 services)
4. AgriWater (5 services)
5. Evidence Provenance (4 services)
6. Decision Engine (3 services)
7. Remote Sensing (5 services)
8. Reporting (2 services)

## Consequences
- Reduced operational overhead
- Clearer domain boundaries
- Easier testing and deployment
- Eliminates cross-cutting concerns (per-service config/logging)

## Migration Path
1. Phase 1: Create Platform Core (shared infrastructure)
2. Phase 2: Migrate domain services to bounded contexts
3. Phase 3: Implement import guards to prevent violations
