# ADR-011: Duplication Elimination Protocol

## Status
Accepted

## Context
ECO-01/21 identifies multiple duplicate implementations of the same scientific algorithms, particularly Penman-Monteith (CONFLICT-001).

## Decision
Eliminate all duplicates by redirecting to canonical implementations:
1. Single implementation per scientific model
2. Canonical IDs (CANON-XXX) as source of truth
3. Legacy implementations deprecated with timeline
4. Static analysis detects duplicates

### Duplication Matrix
| Type | Files Affected | Action |
|------|---------------|--------|
| Scientific models | 5 files | Redirect to CANON |
| Data handlers | 8 files | Consolidate in engine |
| Utilities | 15 files | Platform Core module |
| Logging | 25 files | Centralized logging |

## Consequences
- Single source of truth
- Eliminates inconsistent results
- Reduces maintenance burden
- Simplifies testing

## Detection Tools
```bash
python tools/detect_duplicates.py --dir engine/ services/
python tools/similarity_scan.py --threshold 0.9
```
