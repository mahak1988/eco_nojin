# ADR-008: Evidence Chain Architecture

## Status
Accepted

## Context
Evidence from scientific models must be traceable through the decision pipeline. Without provenance tracking, decisions cannot be audited or reproduced.

## Decision
Implement strict evidence chain: `Engine → Evidence → Decision → AI → User`

### Evidence Tag Schema
```json
{
  "evidence_id": "EVID-2026-XXX",
  "source": "CANON-001",
  "trust_level": "HIGH",
  "provenance_chain": ["CMIP6", "WRF", "hydroma/et"],
  "confidence": 0.92,
  "units": "mm/day",
  "validation_method": "benchmark_against_modis"
}
```

### Trust Levels
- **HIGH**: Peer-reviewed models, satellite data
- **MEDIUM**: Climate projections, interpolated data
- **LOW**: AI predictions, user input

## Consequences
- Full auditability of all decisions
- Trust-weighted decision making
- AI inputs properly validated
- Reproducibility of scientific results
