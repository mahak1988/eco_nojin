# ADR-005: UNIFORMAT Unit Standardization Protocol

## Status
Accepted

## Context
Legacy code mixes Imperial and SI units, causing CONFLICT-009. Models produce inconsistent results due to unit mismatches.

## Decision
Adopt UNIFORMAT: All C++ kernels use SI units (meters, kilograms, seconds, Kelvin). Unit conversion happens at the Engine Gateway boundary.

### Standard Units
| Quantity | Unit | Symbol |
|----------|------|--------|
| Length | meter | m |
| Mass | kilogram | kg |
| Time | second | s |
| Temperature | Kelvin | K |
| Precipitation | mm/day | mm d⁻¹ |
| ET | mm/day | mm d⁻¹ |
| Flow | m³/s | m³ s⁻¹ |

## Consequences
- All calculations in consistent units
- Unit validation at Engine Gateway
- Evidence tags include unit information
- Eliminates unit-related calculation errors

## Implementation
- Python validates units at boundary
- C++ kernels assume SI inputs
- Evidence Engine stores provenance with units
- Test: `test_unit_consistency.cpp`
