# ADR-002: Python/C++ Boundary Protocol

## Status
Accepted

## Context
C++ numerical kernels need to interface with Python scientific engine. Performance is critical for large-scale hydrological computations.

## Decision
Use a multi-mechanism boundary:
- **ctypes** for simple function calls
- **pybind11** for complex object interfaces
- **Buffer Protocol** for zero-copy array transfer

All numerical computation stays in C++; Python orchestrates.

## Consequences
- Zero-copy data transfer eliminates serialization overhead
- C++ remains testable with dedicated test suite (21 test files)
- Python interface uses numpy arrays for compatibility
- Boundary tested with `test_buffer_protocol.cpp`, `test_integration.cpp`
