# ADR-007: Canonical Asset Registry

## Status
Accepted

## Context
Multiple implementations of the same scientific model exist (CONFLICT-001). Users don't know which implementation is authoritative.

## Decision
Establish a Canonical Asset Registry with CANON-XXX identifiers:
- Each scientific model has one canonical implementation
- Canonical IDs reference FAO standards where applicable
- All implementations must reference their canonical counterpart
- Legacy implementations deprecated and removed
