# ADR-006: Scientific Model Maturity Scale

## Status
Accepted

## Context
Models have varying levels of scientific validation, from peer-reviewed to stubs. Without a maturity scale, all models are treated equally, leading to incorrect scientific conclusions.

## Decision
Adopt a 5-level maturity scale:
1. **VERIFIED** — Peer-reviewed, field-validated
2. **SCIENTIFICALLY_SUPPORTED** — Theory-backed, partially validated
3. **IMPLEMENTATION_VERIFIED** — Code matches theory, not field-validated
4. **CODE_ONLY** — Implementation only, no scientific basis
5. **STUB** — Placeholder, non-functional

### Technology Classification
| Maturity | Category |
|----------|----------|
| VERIFIED | CORE |
| SCIENTIFICALLY_SUPPORTED | IMPORTANT |
| IMPLEMENTATION_VERIFIED | OPTIONAL |
| CODE_ONLY | RESEARCH |
| STUB | LEGACY/REMOVE |

## Consequences
- Clear model categorization for users
- Risk-aware decision making
- Evidence Engine assigns trust levels
- AI isolation enforced for lower maturity models
