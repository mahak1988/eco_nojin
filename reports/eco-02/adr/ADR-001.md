# ADR-001: Canonical 7-Layer Architecture

## Status
Accepted

## Context
The Eco Nojin project has 73 microservices with unclear architectural boundaries. Scientific models are duplicated, AI components are unisolated, and there's no clear dependency direction.

## Decision
Adopt a canonical 7-layer architecture with strict dependency rules:
1. Product Experience (UI)
2. Application Orchestration
3. Decision (Tasmimyar)
4. Knowledge (Daneshyar)
5. Evidence Engine
6. Domain Services (Hydroma)
7. Engine Gateway → Scientific Engine → C++ Numerical Kernels

## Consequences
- Clear separation of concerns
- Enforced boundaries prevent coupling
- AI isolation through Evidence Engine layer
- Scientific core remains stable and reproducible
- C++ kernels handle all numerical computation
