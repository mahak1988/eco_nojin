# ADR-014: Technology Classification Framework

## Status
Accepted

## Context
Without technology classification, experimental or deprecated components receive equal investment as mission-critical systems.

## Decision
Classify all technologies into 6 categories:
- **CORE**: Mission-critical, must maintain (8 models)
- **IMPORTANT**: Necessary, optimize but maintain (7 models)
- **OPTIONAL**: Useful but not essential (5 models)
- **RESEARCH**: Experimental, isolate (4 AI components)
- **LEGACY**: Deprecated, plan removal (duplicates, violations)
- **REMOVE**: Critical violation (ECO-LEGACY-001 violations)

### Classification Criteria
| Category | Criteria |
|----------|----------|
| CORE | Directly impacts scientific accuracy |
| IMPORTANT | Supports core functionality |
| OPTIONAL | Enhancement only |
| RESEARCH | Experimental, unvalidated |
| LEGACY | Superseded, deprecated |
| REMOVE | Violates architectural principles |

## Consequences
- Clear investment priorities
- Risk-aware resource allocation
- Systematic legacy removal
- AI components properly isolated

## Investment Allocation
| Category | Budget Allocation |
|----------|-------------------|
| CORE | 50% |
| IMPORTANT | 30% |
| OPTIONAL | 10% |
| RESEARCH | 10% |
| LEGACY | 0% (deprecate) |
| REMOVE | 0% (remove) |
