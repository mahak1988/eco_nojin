# ADR-013: Knowledge Types Integration (Daneshyar)

## Status
Accepted

## Context
The project has 9 distinct knowledge types that need integration into the decision pipeline. Without classification, knowledge sources are treated uniformly regardless of reliability.

## Decision
Map 9 Knowledge Types (KT-001 to KT-009) to architecture layers:
1. **KT-001 Scientific Theory** → Scientific Engine (CORE)
2. **KT-002 Engineering Method** → Domain Services
3. **KT-003 Domain Expertise** → Decision Engine
4. **KT-004 Observational Data** → Evidence Engine
5. **KT-005 Empirical Formula** → Scientific Engine
6. **KT-006 Institutional Knowledge** → Decision Engine
7. **KT-007 Regulatory Knowledge** → Decision Engine
8. **KT-008 Indigenous Knowledge** → Knowledge Layer
9. **KT-009 AI/ML Knowledge** → AI Layer (isolated)

### Trust Propagation
```
KT-001 (THEORY) → HIGH trust
KT-002 (ENGINEERING) → MEDIUM-HIGH trust
KT-003 (DOMAIN) → MEDIUM trust
KT-004 (OBSERVATION) → HIGH trust
KT-009 (AI) → LOW trust
```

## Consequences
- Knowledge-aware trust levels
- Proper integration of local/institutional knowledge
- AI knowledge properly isolated and validated
