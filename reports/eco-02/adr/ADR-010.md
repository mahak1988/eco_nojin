# ADR-010: Import Guard Protocol (ECO-LEGACY-001)

## Status
Accepted

## Context
Legacy code allows imports from `engine/` in `services/`, creating tight coupling that violates architectural boundaries (ECO-LEGACY-001).

## Decision
Implement import guards at the Python module level:
1. All `services/` modules check for `engine/` imports
2. All `ai/` modules check for `engine/` imports
3. CI/CD pipeline blocks violations

### Implementation
```python
import sys
def _guard_imports():
    frame = sys._getframe(1)
    module = frame.f_globals.get('__name__', '')
    if 'services' in module:
        raise ImportError(f"ECO-LEGACY-001: Services cannot import from engine")
```

## Consequences
- Enforced architecture boundaries
- Engine becomes standalone library
- Prevents accidental coupling
- Clear ownership of modules

## Verification
```bash
# CI/CD check
python tools/check_imports.py --root . --forbidden "services.*from.*engine"
```

## Violation Response
1. BLOCK the commit
2. Log violation with context
3. Require architectural review
