# ماژول مدیریت یکپارچه منظر (ILM)

## ساختار حکمرانی
- شورای منظر روستا (۵-۷ عضو)
- مدیر منظر (Landscape Manager)
- نمایندگان بخش‌ها (بازارچه، گردشگری، کشاورزی، دانش)

## صندوق مدیریت منظر
- کارمزد ۱٪ از هر تراکنش
- توزیع با تأیید شورا
- شفافیت بلاکچینی

## مدل‌ها
- `Village`: روستا یا منظر
- `GovernanceMember`: عضو حکمرانی
- `LandscapeFund`: صندوق توسعه
- `FundDistribution`: توزیع وجوه
