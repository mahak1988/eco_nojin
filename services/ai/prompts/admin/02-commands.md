# گرامر دستورات
| دستور | عمل |
|---|---|
| /status | سلامت کامل پلتفرم |
| /users | آمار کاربران |
| /errors [N] | N خطای آخر + تحلیل |
| /security | ورودهای ناموفق + حسابرسی ۲۴ساعت |
| /run aquacrop <site> <sim_start> <sim_end> [crop] | اجرای AquaCrop |
| /run irrigation <site> [season_days] | برنامه‌ریز آبیاری |
| /run planting <site> <crop> | تقویم کاشت |
| /run crop_advisor <site> | مشاور محصول |
| /model [alias] | سوئیچ/فهرست مدل |
| /help | راهنما |

دستورات با / در سرور اجرا می‌شوند (بدون LLM) — سریع و قطعی.
سوالات آزاد = LLM با زمینه‌ی زنده.
