# ۰۸. استقرار و بهره‌برداری

**وضعیت:** تأیید شده | **نسخه:** ۱.۰.۰ | **زبان:** فارسی

## ۱. محیط توسعه

- **بک‌اند:** پایتون 3.11 در `.venv`، FastAPI + Uvicorn.
  اجرا: `uvicorn services.api_gateway.main:app --reload` (از ریشه مخزن).
- **فرانت‌اند:** Next.js (pnpm). اجرا: `pnpm install && pnpm dev`.
  دسترسی LAN در توسعه در `next.config.js` (`allowedDevOrigins`) پیکربندی شده.
- **تست‌ها:** `pytest` از ریشه مخزن (۱۲۶ تست: واحد + یکپارچه + بنچمارک). تست‌های هسته C++: `ctest` یا اجرای مستقیم `tests/test_hydroma.cpp`.

## ۲. زیرساخت به‌صورت کد (فعلی)

`docker-compose.yml` فراهم می‌کند:

| سرویس | ایمیج | کاربرد |
|---|---|---|
| postgis | `postgis/postgis:16-3.4` | دیتابیس مکانی (هدف تولید) |
| redis | `redis:7-alpine` | کش / صف Celery |

⚠ فایل compose شامل رمز جایگزین `***` است — پیش از هر محیط مشترک، با اسرار واقعی جایگزین شود.

## ۳. پیکربندی

- `.env.example` ← کپی به `.env`؛ کلیدها: `PROJECT_NAME`، `ENGINE_NAME`، `ENVIRONMENT`، `DATABASE_URL`، `REDIS_URL`.
- حالت پژوهشی پیش‌فرض SQLite؛ تولید `DATABASE_URL` را به PostGIS تغییر می‌دهد (`postgresql+psycopg://…`).

## ۴. CI/CD (برنامه‌ریزی‌شده)

- `deploy/ci/` و `deploy/k8s/` اسکلت خالی‌اند.
- خط لوله هدف: lint ← تست واحد/یکپارچه ← ساخت C++ + ctest ← ساخت فرانت‌اند ← ایمیج کانتینر ← استقرار (مانیفست k8s یا پلتفرم مدیریت‌شده).
- **پیش‌نیاز فوری:** راه‌اندازی مخزن Git (پروژه هنوز تحت کنترل نسخه نیست) و افزودن CI از اولین commit.

## ۵. مشاهده‌پذیری (برنامه‌ریزی‌شده)

- لاگ ساخت‌یافته (JSON)، شناسه درخواست.
- اندپوینت سلامت وضعیت ماژول‌ها را نشان می‌دهد (`/api/v1/health`).
- متریک (Prometheus) و ردیابی (OpenTelemetry) برای دروازه و موتور.

## ۶. پشتیبان‌گیری و بازیابی

- PostGIS: `pg_dump` زمان‌بندی‌شده / آرشیو WAL؛ دیتابیس پژوهشی SQLite: snapshot سطح فایل.
- داده ماهواره/هواشناسی از APIهای بالادستی دوباره قابل دریافت است؛ سیاست بی‌اعتبارسازی کش (diskcache) لازم است.

## ۷. محیط‌ها

۱. **پژوهش محلی** — SQLite، ماژول‌های درون‌حافظه‌ای، داده ماهواره شبیه‌سازی‌شده.
۲. **پایلوت آزمایشی** — PostGIS + Redis، تایل‌های ماهواره واقعی، فعال‌سازی auth.
۳. **تولید** — k8s، TLS، vault اسرار، گردش کار کربن معتبر، MRV و دفتر کل واقعی.
