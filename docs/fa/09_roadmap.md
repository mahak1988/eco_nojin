## ۲. انجام‌شده (تأییدشده)

- موتور HyDroMa: روندیابی Muskingum-Cunge، فیزیک خاک van Genuchten، شاخص‌های پوشش گیاهی، ET0 با FAO-56/Hargreaves، RUSLE (هسته C++، ۳۵ تست سبز).
- دروازه API با ۱۱ حوزه روتر؛ اندپوینت سلامت.
- بازارچه (کاتالوگ، سفارش، ردیابی) — درون‌حافظه‌ای.
- محاسبه‌گر برآورد کربن با ثبت پروژه.
- موتور سناریو (SSP، محصول، چه‌می‌شد، مونت‌کارلو).
- خط لوله تحلیل ماهواره (جستجوی STAC + باندهای شبیه‌سازی‌شده).
- دستیار دانشی RAG (TF-IDF، ۱۰ سند هم‌راستا با FAO).
- فرانت‌اند PWA با Next.js، ۱۴ زبان، قلاب‌های آفلاین، پیکربندی Capacitor.
- دروازه USSD/SMS (en/fa/ar).
- مجموعه تست: در آخرین اجرای کامل ۱۲۵ از ۱۲۶ پاس (یک assert کهنه در انتظار اصلاح).

## ۳. گام‌های بعدی فوری (به ترتیب اولویت)

۱. **Git + CI** — راه‌اندازی مخزن؛ پین‌کردن وابستگی‌ها؛ اجرای تست در CI.
۲. **داده ماهواره واقعی** — جایگزینی باندهای شبیه‌سازی‌شده با دانلود واقعی GeoTIFF؛ افزودن پوشش‌ابری و پرچم کیفیت.
۳. **رفع عیوب شناخته‌شده** — باگ import دیتاتایم در اندپوینت تأیید کربن؛ تست کهنه `mobile_features`؛ CORS وحشی؛ انکودینگ فارسی README.
۴. **احراز هویت/مجوز** — پیاده‌سازی سرویس auth (OIDC) و محافظت از عملیات نوشتن.
۵. **مسیر کربن** — انتخاب متدولوژی Verra (ARR یا VM0042)، پیاده‌سازی مبنا/افزایشی/نشت/ماندگاری؛ تا راستی‌آزمایی معتبر، `/verify` صریحاً داخلی بماند.
۶. **ارتقای لایه داده** — شِما PostGIS + مهاجرت Alembic؛ ماندگارسازی وضعیت بازارچه/کربن/sync.

## ۴. نقاط عطف فاز ۳ تا ۵

- **EWS:** اتصال NASA POWER و فیدهای پیش‌بینی به شاخص‌های خشکسالی/سیلاب با هشدار آستانه‌ای از طریق SMS/USSD.
- **بیمه:** قراردادهای شاخص‌محور روی سری تاریخی NDVI/بارش.
- **مسیریابی عشایر:** دسترسی علوفه از سری زمانی NDVI + کریدورهای کوچ.
- **دفتر کل و MRV:** هش رمزنگاری اندازه‌گیری‌ها؛ یکپارچه‌سازی بلاک‌چین کنسرسیومی؛ امضای آماده PQC (ML-KEM/ML-DSA).
- **اکوتوریسم و اقتصاد گیگ:** فهرست‌ها، نظرات، پرداخت‌های خرد.
- **APIهای بین‌المللی:** خروجی OGC API Features + WaterML 2.0؛ پروفایل‌های تبادل داده GODAN/FAO.
