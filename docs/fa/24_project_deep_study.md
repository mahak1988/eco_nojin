## ۲) معماری

- **موتور علمی (`engine/hydroma`):** ماژول‌های خاک، اقلیم، هیدرولوژی، فرسایش،
  کربن، ماهواره، سناریو + **هسته C++20 (`engine/cpp_core`)** با اتصال
  pybind11/ctypes (هیدرولیک ریچاردز، سنت-ونان، FAO-56، RUSLE، نمونه‌برداری).
- **سرویس‌ها (`services/`):** api_gateway (۱۴۷ اندپوینت)، auth (JWT)، ledger،
  notification، reporting، workflow.
- **فرانت (`frontend/`):** Next.js App Router + shadcn/Radix UI kit + charts kit
  (recharts) + سیستم i18n سفارشی + PWA.
- **داده:** کلاینت‌های CDSE (Copernicus)، CDS/EWDS/ADS، NASA POWER، SEPAL؛
  دیتابیس SQLite فعلی با مایگریشن alembic (هدف: PostgreSQL).
- **بلاک‌چین:** رجیستری کربن و ردیابی زنجیره تأمین — **پیاده‌سازی شبیه‌سازیشده**
  (مستندات فاز ۸: مهاجرت به VerificationOracle).
- **ML:** مدل PINN (PyTorch) + دستیار RAG با مدل محلی (Ollama).

## ۳) نقاط قوت

- پوشش تستی قوی و سبز (۳۷۱+۱۸)؛ هسته C++ با تست کامل.
- پوشش وسیع دامنه علمی: ۹+ ماژول تخصصی، شاخص‌های ماهواره‌ای، سناریوهای اقلیمی.
- چندزبانه واقعی (۱۴ زبان، RTL کامل برای fa/ar/ur، فونت Vazirmatn خود-میزبان).
- داده‌نمایی خوب: نمودارهای هیدرولوژی با log-scale، مقایسه سناریوهای SSP.
- UI kit استاندارد shadcn/Radix با data-table فارسی‌شده (جستجو/مرتب‌سازی/CSV).
- مستندات دوزبانه گسترده (en 00-21 + fa) و استانداردهای داخلی (STD-001..015).
- معماری سرویس‌گرا و موتور ماژولار — زمینه‌ساز افزودن ماژول‌های پژوهشی.

## ۴) ریسک‌ها و مشکلات (اولویت‌بندی‌شده)

### 🔴 بحرانی (رفع فوری)
1. **کرش صفحه `/science`:** `frontend/components/science/science-dashboard.tsx:110`
   — `useMemo` در سطح ماژول (خارج از کامپوننت) → Invalid hook call در runtime.
   (راستی‌آزمایی شد: خط ۱۱۰ دقیقاً همین است.)
2. **افشای اعتبارنامه در گیت:** `.env.backup` و
   `engine/hydroma/config/settings.py.env-backup` **در گیت ردیابی می‌شوند**
   (تأیید با `git ls-files`). باید از تاریخچه پاک شوند + چرخش کلیدها.
3. **PWA عملاً غیرفعال:** `sw.js` (network-first) نوشته شده ولی
   `registerServiceWorker` هرگز صدا زده نمی‌شود (تنها در کامپوننت orphan)؛
   آیکون‌های PNG جای‌نشان ۷۰ بایتی → خلاف وعده آفلاین-فیرست.

### 🟠 بالا
4. **کلید JWT هاردکد** (گزارش بک‌اند) — باید به env منتقل و چرخانده شود.

   (۱۵۴ صفحه) — ناسازگاری و هزینه نگهداری مضاعف.

   نمی‌رسد؛ هیچ `error.tsx`/`not-found.tsx`/`loading.tsx` هم وجود ندارد.
