# ۰۱. معماری: پلتفرم ترکیبی علمی-محاسباتی

**وضعیت:** تأیید شده | **الگو:** یکپارچه ماژولار (Modular Monolith) با تکامل به سمت میکروسرویس‌ها

## ۱. معماری سطح بالا
سیستم از یک معماری API-First و تفکیک‌شده پیروی می‌کند که موتور محاسباتی سنگین را از برنامه‌های کاربردی مواجه با کاربر جدا می‌سازد.

۱. **رابط‌های کاربری (فرانت‌اند و USSD):** Next.js (وب/PWA) با پشتیبانی از ۱۴ زبان (i18n)، دروازه‌های SMS/USSD برای دسترسی آفلاین روستایی، و هوش مصنوعی صوتی (IVR) برای کاربران کم‌سواد.
۲. **دروازه API و سرویس‌ها:** سرویس‌های مبتنی بر FastAPI که احراز هویت، ارکستراسیون گردش کار، دفتر کل (Ledger) و اعلانات را مدیریت می‌کنند.
۳. **موتور HyDroMa (Python + C++):**
   - **لایه پایتون:** ارکستراسیون، دریافت داده (ماهواره/IoT)، خطوط لوله ML، دستیار دانشی مبتنی بر RAG و نقاط پایانی API.
   - **هسته C++:** حل‌کننده‌های عددی با کارایی بالا برای معادله ریچاردز (آب زیرزمینی)، سنت-ونانت (هیدرولوژی) و RUSLE (فرسایش). اتصال به پایتون از طریق `pybind11`.
۴. **لایه داده (حالت پژوهشی):** 
   - **DuckDB:** برای پرس‌وجوهای تحلیلی سریع روی داده‌های سری زمانی اقلیمی و سنسورها.
   - **SQLite / GeoPackage:** برای هندسه‌های مکانی، پروفایل‌های خاک و مرزهای مزارع.
   - **سیستم فایل محلی:** برای تصاویر ماهواره‌ای خام (GeoTIFF/NetCDF).
۵. **لایه اعتماد و دفتر کل:** هش کردن رمزنگاری‌شده داده‌های MRV، آماده‌سازی برای امضاهای پساکوانتومی و یکپارچه‌سازی با بلاکچین کنسرسیومی.

## ۲. جریان داده (مثال: توصیه آبیاری)
۱. **دریافت:** پایتون داده‌های API هواشناسی محلی و سنسور رطوبت خاک را دریافت می‌کند.
۲. **پردازش:** HyDroMa کرنل C++ فائو-۵۶ (Penman-Monteith) را برای محاسبه ET0 فراخوانی می‌کند.
۳. **بهبود با AI:** مدل ML خروجی فیزیکی را بر اساس داده‌های تاریخی عملکرد محلی تصحیح می‌کند.
۴. **استانداردسازی:** خروجی بر اساس OGC API Features و WaterML 2.0 قالب‌بندی می‌شود.
۵. **ارسال:** به زبان محلی کاربر ترجمه شده و از طریق SMS یا داشبورد ارسال می‌گردد.

## ۳. امنیت و حریم خصوصی
- **حاکمیت داده:** کشاورزان مالک داده‌های خود هستند. داده‌های تجمیع‌شده پیش از استفاده خارجی ناشناس‌سازی می‌شوند.
- **آمادگی پساکوانتومی:** معماری، رابط‌هایی را برای الگوریتم‌های تأییدشده NIST PQC (مانند ML-KEM و ML-DSA) جهت امنیت آینده دفتر کل و API حفظ می‌کند.
