## ۲) راه‌حل — مرکز شبیه‌سازهای علمی واقعی

**جدید** `components/simulators/ScientificHub.tsx` — جایگزین کامل:
- نوار ورودی: مختصات، شیب، مساحت حوزه، محصول (گندم/ذرت/جو) + اجرای زنجیره + نشان کش
- ۸ تب با خروجی واقعی زنجیره (بدون fallback — مقادیر غایب «—»):
  - **نمای کلی**: فرسایش (RUSLE)، SOC نهایی (RothC)، عملکرد (AquaCrop)، قابلیت اطمینان آب (Pywr)
  - **فرسایش**: جدول ضرایب R/K/LS/C/P واقعی
  - **کربن**: SOC اولیه→نهایی، استخرهای DPM/RPM/BIO/HUM/IOM، نمودار سری ۲۰ ساله `annual_series`
  - **محصول**: عملکرد، زی‌توده، آبیاری، بهره‌وری آب، تاریخ برداشت
  - **آب**: نمودار میله‌ای تأمین ماهانه + ذخیره مخزن (`supply_series`/`storage_series` واقعی)
  - **سیلاب**: وضعیت HEC-RAS صادقانه + نقشه deck.gl
  - **بهینه‌سازی**: پارتو NSGA-II
  - **SWAT+**: وضعیت آماده‌سازی + لینک دانلود رایگان

**جدید** `components/simulators/FloodZoneMap.tsx` — نقشه سیلاب با **deck.gl 9.3**:
- `ScatterplotLayer` برای لایه NDVI واقعی (Sentinel-2) و سلول‌های عمق سیلاب HEC-RAS
- بدون خروجی واقعی → پیام صادقانه + مقدار تقریبی Manning + لینک دانلود رایگان USACE
- lazy-load (چانک مجزا ۵۷۳kB — فقط در تب سیلاب لود می‌شود)

**توسعه** `pages/HydromaDashboard.tsx` — چارت‌های نمایشی به داده واقعی متصل شدند:
- WaterBudgetChart: بارش/رواناب واقعی (ERA5 + مدل Pywr)، ET0 مرجع، تغذیه آبخوان ۰ (مدل‌سازی‌نشده)
- CarbonForecastChart: SOC اولیه واقعی SoilGrids
- ErosionRiskMap: فرسایش آبی واقعی RUSLE؛ بادی مدل‌سازی‌نشده (خاکستری)
- LivestockEconomicsChart: خالی (بدون داده واقعی)
- برچسب صداقت زیر چارت‌ها: هیچ عدد ساختگی

**بک‌اند** `chain_runner.py`: `annual_runoff_mcm` به `inputs` اضافه شد (مقدار واقعی جریان ورودی Pywr — ۰.۸۹۹ MCM تهران).
