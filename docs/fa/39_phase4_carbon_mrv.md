# فاز ۴ — MRV / حسابداری کربن (رایگان)

> وضعیت: **هسته پیاده‌سازی‌شده و تست‌شده** — HTTP 200 در ۰.۲۶ ثانیه؛ انتخاب: فاز ۴ (به‌جای نصب دستی باینری‌ها).

## تصمیم
بین «فاز ۴» و «نصب SWAT+/HEC-RAS» → **فاز ۴** انتخاب شد: باینری‌ها نصب GUI بزرگ و دستی هستند (لینک‌های رایگان داخل برنامه قرار دارد و اینتگریشن آماده است)، اما MRV ارزش علمی/محصولی فوری دارد و کاملاً رایگان قابل اجراست.

## اجزای جدید (همه رایگان)

| فایل | کارکرد |
|---|---|
| `services/scientific_motors/carbon_mrv.py` | موتور حسابداری کربن خاک — روش **Verra VM0032** (ساده‌شده): ΔSOC → tCO2e (×۳.۶۶۷ IPCC)، ضریب ماندگاری، حالت داده صادقانه |
| `services/mrv/kobo.py` | کلاینت **KoboToolbox** (سطح رایگان): خواندن نمونه‌های میدانی SOC از فرم نظرسنجی؛ بدون توکن → `requires_credentials` صادقانه |
| `services/api_gateway/routers/mrv.py` | `POST /api/mrv/carbon-budget` — زنجیره واقعی RothC (SOC اولیه/نهایی) + داده میدانی اختیاری |

## رفتار صادقانه
- بدون داده میدانی → `data_mode: modelled_estimate` + `requires_field_data`
- با KOBO_TOKEN/KOBO_FORM_ID → میانگین نمونه‌های واقعی جایگزین SOC اولیه → `field_verified`
- برآورد مدل است، **گواهی Verra/Gold Standard نیست** — صراحتاً در پاسخ و UI نوشته می‌شود

## شواهد تست (تهران، ۱۰۰ هکتار)
```
POST /api/mrv/carbon-budget → HTTP 200
delta_co2e_total: -337.73 tCO2e   (SOC 63.72 → 62.80 t C/ha)
data_mode: modelled_estimate | status: requires_field_data
```
نتیجه منفی صادقانه است: سناریوی پایه بدون مداخله در حال **افت کربن** است — خروجی واقعی مدل، نه عدد خوشایندسازی‌شده.

## فرانت‌اند
تب «MRV کربن» در مرکز شبیه‌سازها (`ScientificHub`): مساحت + نوع مدیریت + دکمه محاسبه → بودجه tCO2e، SOC اولیه/نهایی، حالت داده، وضعیت KoboToolbox.

## قدم بعدی (فاز ۴-ب)
اتصال واقعی KoboToolbox (ثبت‌نام رایگان + توکن)، ماژول MRV در داشبورد، استاندارد Gold Standard و گزارش‌های MRV قابل‌خروجی.
