# ۰۳. پلتفرم اکو نوژین

**وضعیت:** تأیید شده | **نسخه:** ۱.۰.۰ | **زبان:** فارسی

## ۱. اکو نوژین چیست

اکو نوژین پلتفرمی بین‌المللی و استاندارد-محور برای احیای اکوسیستم، کشاورزی هوشمند، مدیریت آب و خاک، رونق روستایی، حمایت از دامداران، انگیزه‌های کربنی، بازارچه و اکوتوریسم است که بر پایه موتور علمی HyDroMa ساخته شده (رجوع: `02_hydroma_engine.md`).

## ۲. کاربران هدف

- کشاورزان خرد — بهینه‌سازی عملکرد، بهره‌وری آب، تاب‌آوری اقلیمی
- دامداران و عشایر — مسیریابی کوچ، پایش علوفه، بیمه دام
- جوانان و زنان روستایی — اقتصاد گیگ، اکوتوریسم، صنایع تبدیلی
- تعاونی‌ها — فروش گروهی و تأمین نهاده
- دولت‌ها و NGOها — ابزارهای MRV برای تعهدات ملی اقلیمی
- خریداران و سرمایه‌گذاران اثرگذار — محصولات ارگانیک و کربن راستی‌آزمایی‌شده

## ۳. رابط‌های کاربری

۱. **وب/PWA** (`frontend/`): Next.js، ۱۴ زبان، PWA قابل‌نصب با قلاب‌های ذخیره آفلاین (IndexedDB)، سرویس‌ورکر، آماده بسته‌بندی با Capacitor برای اندروید/iOS. پنل‌ها: خاک، ماهواره، برنامه‌ریز کشت، سناریو، کربن، آبخیز، بازارچه، بنچمارک، امکانات موبایل، چت هوش مصنوعی.
۲. **دروازه USSD/SMS** (`engine/hydroma/ussd/` + `services/api_gateway/routers/ussd.py`): دسترسی با گوشی‌های ساده با فرمت‌های webhook اپراتورها (Africa's Talking، Twilio، کاوه‌نگار، ژنریک). منوی USSD `*384*73#` و دستورهای SMS (SOIL، CROP، PRICE، WEATHER، ASK).
۳. **صدای هوشمند (IVR):** برنامه‌ریزی‌شده برای کاربران کم‌سواد.

## ۴. دروازه API

دروازه FastAPI (`services/api_gateway/`) با مسیرهای `/api/v1/*`:

| حوزه | اندپوینت‌ها |
|---|---|
| خاک و مواد | CRUD پروفایل خاک، فرمول‌سازی C/N کمپوست |
| ماهواره | تحلیل نقطه‌ای (NDVI/EVI/SAVI/NDWI/NBR)، سلامت |
| سناریو | پیش‌بینی SSP، شبیه‌سازی محصول، چه‌می‌شد، مونت‌کارلو |
| کربن | انواع پروژه، محاسبه، ثبت، تأیید |
| بازارچه | محصولات، تولیدکنندگان، سفارش‌ها، ردیابی |
| آبخیز | بندهای رسوب‌گیر، ترانشه کانتور، هلالی‌های آبگیر |
| دستیار هوش مصنوعی | چت (RAG)، سلامت |
| همگام‌سازی | sync دسته‌ای آفلاین موبایل |
| USSD/SMS | مدیریت webhookها |
| بنچمارک | مقایسه کارایی |
| سیستم | `/api/v1/health` |

## ۵. وضعیت سرویس‌ها (صادقانه)

| سرویس | وضعیت |
|---|---|
| api_gateway | پیاده‌سازی‌شده (FastAPI) |
| auth، ledger، workflow، notification، reporting | **Placeholder** (فقط چاپ نام) |
| blockchain، ml، data، deploy | اسکلت خالی (`.gitkeep`) |

## ۶. راهبرد موبایل/آفلاین

- سرویس‌ورکر برای کش پوسته اپ؛ قلاب‌های ذخیره آفلاین برای دوربین، موقعیت و عملیات صف‌شده؛ اندپوینت `/api/v1/sync/batch` برای ارسال عملیات صف‌شده.
- sync فعلی موارد را لاگ می‌کند و موفق برمی‌گرداند (حالت پژوهشی) — بازپخش واقعی و حل تعارض برنامه‌ریزی شده.

## ۷. محدودیت‌های فعلی

- پنل‌های فرانت‌اند آدرس ثابت `http://127.0.0.1:8000` را صدا می‌زنند؛ برای استقرار به base URL پیکربندی‌پذیر نیاز است.
- لایه احراز هویت هنوز وجود ندارد (سرویس auth placeholder است).
- شاخص‌های ماهواره‌ای تا وصل‌شدن دانلود واقعی، داده شبیه‌سازی‌شده‌اند.

## ۸. مسیر موفقیت (مثال)

هواشناسی + رطوبت خاک ← کرنل FAO-56 در HyDroMa محاسبه ET0 ← اصلاح با ML (برنامه‌ریزی‌شده) ← قالب‌بندی OGC/WaterML (برنامه‌ریزی‌شده) ← ارسال محلی‌شده از طریق SMS یا داشبورد.
