## ۱) تقویت هسته مرکزی C++20 (`engine/cpp_core`)

**وضعیت فعلی:** هسته عددی با Richards، Saint-Venant، FAO-56، RUSLE و
نمونهبرداری؛ ۷۰/۷۰ تست؛ اتصال pybind11/ctypes با `hydroma_core.dll`.
(ریچاردز و سنت-ونان در عمل تکبعدی/پایهاند.)

### ۱.۱ معماری (پایه هر کار بعدی)
- تفکیک سه لایه: `core/` (ریاضی محض، بدون I/O)، `api/` (C ABI پایدار
  با `extern "C"` برای ctypes)، `bindings/` (pybind11 برای پایتون).
- افزودن CMake + CI دو-پلتفرمه (Windows/Linux): build + test + benchmark
  در هر push.
- رجیستری توابع (`FunctionRegistry`) تا سرویسها بدون بازکامپایل، مدل جدید
  ثبت کنند (هماهنگ با معماری ماژولار پایتون).

### ۱.۲ الگوریتمهای جدید (اولویت فنی)
1. **ریچاردز 2D/3D:** گسستهسازی حجم محدود + حل خطی GMRES با پیششرطساز
   (ILU) و تکرار Picard/Newton — برای آبخوان و شیبهای واقعی.
2. **سنت-ونان دوبعدی (SWE):** طرح HLLC + محدودکننده slope برای شبیهسازی
   سیلاب دشت (فعلاً ۱D است).
3. **هسته FAO-56 دو-منبعی (Shuttleworth-Wallace):** جداسازی تبخیر خاک و
   تعرق گیاه — دقیقتر از تکمنبعی فعلی.
4. **مدل آب-خاک-گیاه چندلایه:** tipping bucket + جذب ریشه (Feddes).
5. **هسته عملکرد محصول (AquaCrop-مانند):** `B = WP×ΣTr`، شاخص برداشت
   پویا — پایه ماژول توصیهگر آبیاری.
6. **هسته کربن (RothC/Century):** شبیهسازی دههها در C++ (سرعت حیاتی).
7. **هیدرولیک سازهها:** جریان سرریز/روزنه (weir/orifice) برای طراحی بندهای
   اصلاحی (نیاز ماژول آبخیز).
8. **تصادفیسازی:** Xoshiro256** + لاتینهایپرکیوب (LHS) برای عدمقطعیت و
   Monte Carlo.

### ۱.۳ عملکرد و کیفیت
- SIMD/AVX در حلقههای داغ؛ OpenMP برای حلگرهای موازی.
- حافظه پیوسته (SoA)، حذف تخصیصهای مکرر (memory pool).
- پوشش تست هسته >۹۰٪؛ **تست در برابر راهحل تحلیلی** (مثلاً نفوذ
  Green-Ampt، موج ساده) + fuzz برای پایداری عددی.
- بنچمارک رگرسیون در `benchmarks/` (ترند اجرا در CI).

**شاخص موفقیت:** خطای حلگرها <۱٪ در برابر راهحل تحلیلی؛ سرعت ≥۲× نسخه فعلی.

## ۲) توسعه ماژولهای پایه/توسعهنیافته

**وضعیت فعلی:** ماژول ماهواره با داده شبیهسازیشده (earth_search)،
بلاکچین شبیهسازیشده، PINN اسکافولد، مارکتپلیس/ردیابی ناتمام (فاز ۸).

### اولویت ۱ — تکمیل فاز ۸ (تعریفشده)
- موتور توزیع EcoCoin 70/15/10/5 + UI کیف پول (آغاز شده در `f7ef644`).
- مارکتپلیس + ردیابی زنجیره تأمین (QR).
- **مهاجرت VerificationOracle:** جایگزینی بلاکچین شبیهسازیشده با
  رجیستری راستیآزماییشدنی (hash-chain ساده روی PostgreSQL + امضای
  رویدادها) — شفاف و قابل ممیزی.

### اولویت ۲ — سنجشازدور واقعی
- دانلود واقعی Sentinel-2 (CDSE/S3) + پردازش NDVI/EVI/SAVI/NDWI/NBR.
- برچسب اجباری `data_source` (simulated/real) در همه خروجیها — قانون پروژه.
- افزودن شاخص خشکسالی SPEI و تقویم فنولوژی.

### اولویت ۳ — هوش مصنوعی
- PINN: آموزش روی ERA5 واقعی؛ توقف حالت toy.
- RAG: ارتقا از TF-IDF به embedding محلی (مثلاً Ollama/bge-m3) + ارجاعدهی
  دقیق با شماره منبع.
- مدل پیشبینی عملکرد (ML روی داده تاریخی).

### اولویت ۴ — ماژولهای جدید (از سند ۲۲)
- ماشینحساب فرمول کود NPK؛ توصیهگر کود زیستی/اصلاحکننده (بر اساس آزمون
  خاک: N_rate = (نیاز−عرضه)/NUE).
- طراح خودکار سازه آبخیز (SCS-CN + Rational + برآورد هزینه).
- توصیهگر رقم مقاوم (اقلیم/خاک/تنش ← ژنوتیپ) با پایگاه ارقام.
- داشبورد اقلیم (CMIP6 + GISTEMP از سند ۲۳).

### اولویت ۵ — یکپارچگی داده
- یکدیتابیسهکردن (econojin.db / hydroma_research.db)؛ مهاجرت PostgreSQL؛
  پایپلاین DVC واقعی با داده نسخهبندیشده.

## ۴) تکمیل پنل ادمین

**وضعیت فعلی:** پنل واقعی (AdminNav + AdminOverview) با ماژولهای محتوا،
رباتها، خطاها، تنظیمات — اما ناقص.

### پیشنهادها (اولویتبندیشده)
1. **داشبورد مدیریتی (KPI):** کاربران فعال، تراکنشها، خطاها، uptime؛
   نمودارهای recharts + خروجی CSV/PDF؛ فیلتر بازه زمانی.
2. **مدیریت محتوا:** CRUD کامل + وضعیت ترجمه هر محتوا در ۱۴ زبان.
3. **مدیریت رباتها/کانالها:** متریک هر کانال (تلگرام/ایتا/بله/روبیکا +
   USSD/SMS/Voice): پیامها، خطاها، uptime، ارسال آزمایشی.
4. **نمای خطاها:** تجمیع (aggregation)، جستجو، جزئیات stack، retry،
   اتصال به لاگ متمرکز.
5. **مدیریت کاربران و RBAC:** لیست/جستجو، نقشها، غیرفعالسازی،
   احراز دومرحلهای برای ادمین.
6. **مالی/توکن:** پایش توزیع EcoCoin، تراکنشهای ledger، وضعیت کیف پولها.
7. **علمی:** رجیستری مدلها (وضعیت کالیبراسیون)، نشان `simulated/real`
   روی دادهها، گزارش MRV کربن.
8. **تنظیمات امن:** feature flags، بدون نمایش secrets (فقط mask).

## ۵) تقویت لایههای امنیتی

**وضعیت فعلی:** JWT (کلید هاردکد)، `.env.backup` در گیت، rate-limit و
CORS از قبل در env وجود دارند ولی فعال بودن نیازمند راستیآزمایی است.

### ۵.۱ بحرانی (همین هفته)
1. **پاکسازی گیت:** `git filter-repo` برای حذف `.env.backup` و
   `settings.py.env-backup` از تاریخچه + push --force + اعلان به هر همکار.
2. **چرخش همه اسرار:** JWT_SECRET، CDSE/CDS/EWDS/ADS، توکنهای رباتها،
   SECRET_KEY — پس از پاکسازی.
3. **پیشگیری:** `.gitignore` سختگیرانه + pre-commit hook
   (gitleaks/detect-secrets) + اسکن تاریخچه.

### ۵.۲ احراز هویت و نشست
- JWT_SECRET فقط از env؛ الگوریتم RS256/HS256 امن؛ مدت کوتاه + refresh
  چرخشی.
- انتقال توکن از localStorage به **HttpOnly cookie** (کاهش XSS) + CSRF
  protection.
- MFA برای ادمین؛ قفل پس از N تلاش؛ ثبت رویدادهای امنیتی (لاگ ممیزی).

### ۵.۳ API و برنامه
- اعتبارسنجی ورودی (Pydantic — موجود) + **آزمون authz برای هر ۱۴۷
  اندپوینت** (دسترسی غیرمجاز باید 401/403 دهد).
- فعالسازی rate-limit (کلیدهای env موجود) + CORS دقیق + هدرهای امنیتی
  (helmet) + HTTPS اجباری.
- اسکن وابستگیها در CI: pip-audit + npm audit (و راستیآزمایی
  CVE-2025-66478 با Next 16.3.1).

### ۵.۴ داده و زیرساخت
- رمزنگاری در حال استراحت (PostgreSQL TLS + رمز ستونهای حساس)؛
  مدیریت اسرار با secrets manager (بدون env در رپو).
- RLS در Supabase/Postgres؛ جداسازی داده simulated/real در همه لایهها.
- ممیزی تغییرات ledger (hash-chain) و بکاپ رمزنگاریشده.
