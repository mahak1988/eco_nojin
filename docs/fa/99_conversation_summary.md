# خلاصه گفتگو

این سند جهت توافق‌شده پروژه Eco Nojin / HyDroMa را حفظ می‌کند.

## نام‌های پروژه

- موتور: HyDroMa
- پلتفرم: Eco Nojin

## توافق اصلی

- ساخت پلتفرم ماژولار، استاندارد-محور و بین‌المللی.
- استفاده از Python برای ارکستراسیون، هوش مصنوعی، داده و API.
- استفاده از C++ برای هسته محاسباتی علمی پربازده.
- استفاده از TypeScript برای فرانت‌اند و داشبوردها.
- شروع با مستندات، سپس پیشرفت ماژول به ماژول.
- نگه‌داشتن کد و کامنت‌ها به زبان انگلیسی.
- دوزبانه بودن مستندات: انگلیسی و فارسی.
- پشتیبانی از بین‌المللی‌سازی از همان گام نخست.

## محدوده عملکردی

پلتفرم باید این موارد را پشتیبانی کند:

- کشاورزی، مرتع، دام و معیشت روستایی.
- هیدرولوژی، آبخوان، سیلاب، رواناب و آبخیزداری.
- خاک، فرسایش، کودهای زیستی، کمپوست، بیوچار و احیای خاک.
- پایش اقلیم، خشکسالی، پوشش گیاهی و توپوگرافی.
- رشد محصول، آبیاری، توصیه کشت و سناریوسازی.
- مدیریت ریسک، مدیریت بحران و تاب‌آوری.
- احیای اکوسیستم، جنگل‌کاری و بیابان‌زدایی.
- ترسیب کربن، MRV، پاداش و انگیزه‌های توکنی.
- حسابداری، مالی، انبار، بازارچه و اکوتوریسم.
- دانش‌یار، جستجو، یادگیری ماشین و مشاور هوش مصنوعی.
