# ۵۳. فاز ۸ — سه فاز اجرایی (تعریف + شروع فاز ۸-الف)

> تاریخ: 2026-08-27 · بر اساس تقویتهای پیشنهادی کاربر (کالیبراسیون خودکار، شبیهساز سبک مرورگر، AI، CMIP6، خشکسالی، داده باز ایران، استانداردهای باز، امنیت عنکبوتی).

## فاز ۸-الف — یکپارچهسازی و زیرساخت کاربر (شروع: همین چرخه)
1. **پروفایل کاربر واقعی:** صفحه/کارت پروفایل با داده واقعی Supabase (display_name، phone، bio، role، اکو/اعتبارها، قابل ویرایش).
2. **پنل ادمین + تولید محتوا:** کنسول ادمین با داده واقعی (کاربران، استانداردها، دورههای LMS، اعتبارهای صادرشده) — نقشگیتدار.
3. **بازبینی کامل frontend:** صفر فایل خالی/یتیم، اتصال کامل از entry point، ارتقای کیفیت ویجتها.
4. **کتابخانههای جاافتاده (رایگان):** backend (alembic, openmeteo-requests, paho-mqtt, pyfao56, pysheds)، frontend (@tanstack/react-query, react-hook-form, zod) — نصب در صورت جاافتادگی.
5. **اتصال کامل بکاند/فرانت** (Vite proxy، تست اندپوینت).

## فاز ۸-ب — شبیهساز حرفهای + تقویتهای علمی
1. ارتقای سطح شبیهسازها به کیفیت تصاویر/ماهواره (VisualSimulators + deck.gl/maplibre).
2. شبیهسازی سبک مرورگر (RUSLE/RothC در JS، پاسخ < ۵۰۰ms) + اجرای دقیق در بکاند.
3. سناریوهای اقلیمی CMIP6 (SSP) از CDS برای تحلیل ۳۰ ساله.
4. پایش خشکسالی SPI/SPEI + هشدار اولیه (اتصال USSD/SMS).
5. داده باز ایران (سازمان نقشهبرداری، جهاد کشاورزی).
6. کالیبراسیون خودکار: بازخورد IoT/ماهواره به engine/hydroma/calibration (CN، Ks، AWC، C/P-factor).

## فاز ۸-ج — امنیت عنکبوتی (۱۰+ لایه) + استانداردهای باز + AI
1. **فایروال امنیتی عنکبوتی** — تحقیق و پیادهسازی ۱۰+ لایه: WAF (ruleset)، rate limiting/هوشمند، JWT/RLS (Supabase)، هدرهای امنیتی (CSP/HSTS/Helmet)، ورودیسنجی عمیق + ضد SQLi/XSS/CSRF، **ضد فیشینگ** (SPF/DKIM/DMARC + بررسی دامنه + ضد کلون صفحه)، **پساکوانتوم** (CRYSTALS-Kyber/Dilithium در احراز هویت و امضا)، **لایه خودترمیمشونده** (پایش سلامت + راهاندازی مجدد خودکار + شناسایی نفوذ)، honeypot/تله، رفتارشناسی درخواست (Anomaly)، رمزنگاری دادهها (at-rest + in-transit)، zero-trust RBAC + audit logging.
2. OGC API Features + WaterML 2.0 (روادمپ).
3. AI: ارتقای RAG به LLM برای توصیه طبیعی (بندسارها، رواناب…).
4. استقرار رایگان (Vercel + Render/Railway) + اتصال مراکز داده رایگان.
