# ۶۳. برنامهٔ توسعهٔ صفحات عمومی — مقایسهٔ برنامهٔ پیشنهادی با وضعیت واقعی

> تاریخ: ۲۰۲۶-۰۹-۰۸ | مبنای مقایسه: برنامهٔ پیوست سه‌لایه‌ای + وضعیت واقعی کد + گزارش ۶۲
> **وضعیت اجرا: P0 تا P3 پیاده‌سازی شد** (۲۳ مسیر فعال؛ ۳ endpoint جدید بک‌اند؛ جستجو/دسته‌بندی FAQ و بلاگ؛ تغییرات نیازمند دادهٔ واقعی به‌صورت اسکلت صادقانه علامت‌گذاری شدند).

## ۱. تصویر کلی مقایسه

برنامهٔ پیوست، وضعیت را از روی توضیحات متنی تشخیص داده؛ وضعیت واقعی از آن جلوتر است:

| ادعای برنامه | واقعیت کد |
|---|---|
| Contact «فقط فرم + ایمیل» | **به API واقعی وصل است** (`POST /api/v1/contact`، مدل `ContactMessage`، هانی‌پات، ۶ تست) |
| FAQ «۱۱ آیتم» | **۱۲ آیتم** + FAQPage JSON-LD |
| Transparency «فقط گاه‌شمار» | گاه‌شمار + زنجیرهٔ راستی‌آزمایی + تعهد گزارش دوره‌ای |
| Legal «قالب ساده» | نسخه‌بندی v1.0 + لینک متقابل + متن مبتنی بر LEGAL_COMPLIANCE.md |
| سئو (غیر از تنظیمات پایه) | Seo per-page کامل + og.png + sitemap.xml + robots.txt + Organization JSON-LD + ۴۰۴ اختصاصی |
| «۱۱ مسیر» | **۱۲ مسیر فعال** (+۴۰۴) |

**نتیجه:** تقریباً همهٔ «تقویت‌های لایه ۱» برنامه یا انجام شده یا مسیر روشن دارند؛ ارزش اصلی برنامه در **لایه ۲ (۱۰ صفحهٔ جدید)** و **لایه ۳ (۵ صفحهٔ فرود)** است.

### لایه ۳ (فرودها)
- `/investors`: **متر مجاز و فوری** — INVESTOR_PITCH.md موجود است؛ نسخهٔ عمومیِ خلاصه + CTA (بدون اعداد مالی محرمانه بدون اجازه).

## ۳. معماری محتوا (پیشنهاد split در برنامه)

`site.ts` اکنون ~۶۱KB است. پیشنهاد: **split را همزمان با افزودن ۳ صفحهٔ جدید P0 انجام بده** (یک‌بار هزینه، نه دوبار): `src/content/site.ts` (brand/nav/shared) + `pages/*.ts` به ازای هر صفحه + `legal/*.ts`. ایمپورت‌ها در سطح صفحات می‌ماند و SSOT حفظ می‌شود.

## ۴. برنامهٔ اجرایی ادغام‌شده (واقع‌بینانه)

**P0 — نهایی‌سازی هسته (≈ ۱ روز کاری):**
1. صفحهٔ `/developers` (Swagger زنده + نمونه‌ها + نرخ/JWT)
2. FAQ: جستجو + دسته‌بندی (۴ دسته: علم/پلتفرم/کربن/دسترسی)
3. Legal: changelog + print styles؛ Contact: لینک FAQ
4. Home: ستون «چرا اعتماد کنیم» (فکت‌محور: MIT، کوپرنیکوس، بلاکچین — بدون شمارندهٔ جعلی)
5. Refactor محتوا به ساختار split

**P1 — اعتماد و کاهش اصطکاک (≈ ۱–۲ روز):**
6. `/support` راهنمای متنی USSD/SMS/صوت
7. `/status` polling واقعی health
8. `/impact` + `/carbon` اسکلت صادقانه (متریک‌ها تعریف، اعداد منتظر پایلوت)
9. About: چیپ وضعیت فازها + بخش CONTRIBUTING

**P2 — رشد (بعد از پایلوت یا تصمیم):**
10. بلاگ: دسته‌بندی + جستجو + خبرنامه (بک‌اند)
11. `/investors` (با تأیید محتوای مالی) / `/partners` / `/careers` اسکلت‌ها
12. `/pilot-iran` + `/academia` (فرم + بک‌اند + تصمیم کمپین)

**P3 — کمپین‌محور:** `/marketplace` `/resources` ویدیوها/اسکرین‌شات‌ها

## ۵. تصمیم‌های باز (فقط شما می‌توانید)
1. SLA پاسخ تماس (۲۴ ساعت؟) و ساخت ایمیل‌های اختصاصی (security@…)
2. اجازهٔ انتشار نسخهٔ عمومیِ خلاصهٔ INVESTOR_PITCH در `/investors`
3. شروع پایلوت → فعال‌شدن شمارنده‌های واقعی اثر
4. عضویت در الگوی Ag Data Transparent برای اعتماد دادهٔ کشاورزی
