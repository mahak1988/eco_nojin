# ۶۶. برنامهٔ بازطراحی بصری اکو نوژین — رنگ، تایپوگرافی، نسبت طلایی و صفحه‌آرایی

> تاریخ: ۲۰۲۶-۰۹-۱۳ | وضعیت: برنامهٔ اجرایی (منتظر تأیید) | دامنه: کل فرانت‌اند، تمرکز ویژه: صفحهٔ خانه
> این سند جایگزین هیچ کدی نمی‌شود؛ نقشهٔ راه بازطراحی است و پس از تأیید، فازبه‌فاز اجرا می‌شود.

|---|---|---|

| **رنگ‌بندی بی‌قاعده** | ۴ رنگ لهجه (سبز/فیروزه/کهربایی/بنفش) بدون قاعدهٔ سهم؛ بنفش ناگهان در فوتر ظاهر شده | چشم نمی‌فهمد کجا «مهم» است؛ رنگ ارزش signaling خود را از دست داده |

| **بی‌نظمی در گردی و فاصله** | radius مخلوط (12/14/16/21/24/32) و padding‌های موردی | حس اتفاقی بودن؛ نبود ریتم |
| **تایپوگرافی بدون مقیاس** | اندازه‌های موردی (13/14/15/16/17/18/21/24/28/30...) | نبود سلسله‌مراتب خوانشی |

## ۲. مبانی علمی برنامه

### ۲.۱ روان‌شناسی رنگ (چرا این رنگ‌ها، برای چی)
| رنگ | معنا در ذهن مخاطب | نقش در اکو نوژین | سهم |
|---|---|---|---|
| سبز برگ `#3FBF7F` | رشد، احیا، امنیت | **رنگ اصلی**: CTA، اعداد کلیدی، وضعیت فعال | ~۱۰٪ |
| فیروزه `#56C2D6` | آب، شفافیت، اعتماد | لینک‌ها، شاخص‌های آبی، چیپ اطلاع | ~۵٪ |
| کهربایی `#E0B96B` | خاک، گرمای زمین، هشدار ملایم | فقط نوار کربن/اکوکویین و برچسب «در انتظار» | ~۳٪ |
| بنفش `#B7A6E8` | نوآوری، علم | فقط برچسب دستهٔ «چشم‌انداز/علم» — حذف از فوتر | ≤۲٪ |
| سبزین خنثی (زمینه) `#0A1811` | آرامش، عمق، طبیعتِ شب | پس‌زمینه | ~۶۰٪ |
| سطح‌ها `#0D2118 / #122A1F` | لایه‌بندی فضایی | کارت‌ها | ~۲۰٪ |
| متن روشن `#EEF6F0` | وضوح | تیترها و متن اصلی | — |

**قاعدهٔ ۶۰-۳۰-۱۰:** ۶۰٪ زمینهٔ تیرهٔ ساکن، ۳۰٪ سطح‌ها و متن، ۱۰٪ رنگ‌های زنده. رنگ زنده فقط جایی که باید نگاه شود.

### ۲.۲ سواد بصری (خوانش را هدایت کن)
- **سلسله‌مراتب سه‌سطحی متن:** تیتر روشن و درشت ← متن بدنه با کنتراست AA (≥4.5:1) ← متادیتای محو فقط برای اطلاعات غیرحیاتی. (فعلاً سطح دوم و سوم خیلی به هم نزدیک‌اند.)
- **یک زبان تصویری واحد:** همهٔ آیکن‌ها stroke یکسان (1.75px)، همهٔ تصاویر SVG با پالت NDVI (سبز→کهربایی)، بدون عکس ریموت.
- **جهت RTL:** چیدمان آینه‌ای؛ شروع خوانش از راست؛ فلش‌های جهت‌دار همیشه «به جلو» یعنی به سمت چپ در فارسی.
- **فضای منفی = بخشی از طراحی:** حداقل یک «سکوت بصری» بین هر دو سکشن (فاصلهٔ خالی بدون کارت و بدون رنگ).

### ۲.۳ نسبت طلایی و نقاط طلایی
- **مقیاس φ برای فاصله و اندازه (Fibonacci/8px):** `8 · 13 · 21 · 34 · 55 · 89 · 144` — padding کارت 21، فاصلهٔ بین کارت‌ها 13، padding سکشن 89/144.
- **تقسیم طلایی Hero:** ستون متن 61.8٪ و صحنهٔ ماهواره 38.2٪ (در RTL برعکس نمی‌شود؛ متن در سمت شروع).
- **خطوط طلایی (_thirds):_** خط افقی ثلث بالای Hero = محل نشستن تیتر؛ خط ثلث پایین = نوار آمار. در کارت‌ها، آیکن در نقطهٔ تلاقی ثلث بالا-راست.
- **نقاط طلایی:** چهار نقطهٔ تلاقی شبکهٔ ثلث در Hero و نمودارها = جای CTA اصلی و آیکن شاخص.
- **مقیاس تایپوگرافی φ:** H1=44 · H2=34 · H3=21 · Body=16/1.85 (فارسی ارتفاع خط بیشتر) · Caption=13.

### ۲.۴ کادربندی — فقط ۳ نوع کارت
| نوع | ظاهر | کاربرد | حداکثر در هر صفحه |
|---|---|---|---|
| **کارت پایه** | سطح توپر `#0D2118`، بدون سایه، radius 21، padding 21 | اکثر محتوا (قابلیت‌ها، ماژول‌ها، بسته‌ها) | نامحدود (یکدست) |
| **کارت تاکیدی** | حاشیهٔ رنگ لهجه + tint ۸٪ | نوار کربن، فازهای اکوکویین، CTA | ۱–۲ |
| **کارت داده (داشبورد)** | بدون tint، جدول‌مانند، رنگ فقط برای وضعیت | داشبورد و رجیستری | — |
- ممنوع: glass داخل glass، حاشیهٔ رنگی روی همهٔ کارت‌ها، سایه + حاشیه + tint هم‌زمان.

## ۳. توکن‌های جدید (index.css v2 — بازنویسی کامل @theme)

```css
@theme {
  /* زمینه */
  --color-bg:        #06120D;   /* پس‌زمینهٔ پایه — گرم‌تر و آرام‌تر از فعلی */
  --color-surface:   #0D2118;   /* کارت پایه */
  --color-surface-2: #122A1F;   /* سطح برجسته/هاور */
  /* متن */
  --color-ink-1: #EEF6F0;       /* تیتر — کنتراست ~15:1 */
  --color-ink-2: #C9DCD1;       /* متن بدنه — ~9:1 */
  --color-ink-3: #8AA797;       /* متا — ~4.6:1 (AA) */
  /* لهجه‌ها */
  --color-leaf: #3FBF7F;        /* اصلی */
  --color-aqua: #56C2D6;        /* ثانویه/آب */
  --color-sand: #E0B96B;        /* زمین/کربن */
  --color-iris: #B7A6E8;        /* علم/چشم‌انداز (محدود) */
  /* فاصله (φ) */
  --space-1: 8px;  --space-2: 13px;  --space-3: 21px;
  --space-4: 34px; --space-5: 55px;  --space-6: 89px;
  /* گردی واحد */
  --radius-card: 21px;  --radius-pill: 999px;
}
```
- حذف: هاله‌های سه‌گانهٔ همیشگی، `bg-grid` سراسری، gradient متن در چند جا (فقط Hero).
- پس‌زمینهٔ جدید: یک هالهٔ بسیار ملایم در ثلث بالای صفحه + بدون گرید در کل صفحه (گرید فقط داخل صحنهٔ Hero).

## ۶. چک‌لیست پذیرش نهایی

- [ ] هیچ متنی زیر کنتراست 4.5:1 نیست (WCAG AA) — متن‌های بدنه بالای 7:1
- [ ] هر صفحه حداکثر ۲ کارت تاکیدی دارد؛ بقیه کارت پایه
- [ ] همهٔ radiusها 21 یا 999 (pill) هستند؛ هیچ radius دیگری نیست
- [ ] فاصله‌ها فقط از مقیاس φ (8..144) انتخاب شده‌اند
- [ ] خانه ۶ سکشن دارد و بین هر دو سکشن فضای خالی 89px دیده می‌شود
- [ ] رنگ بنفش فقط در برچسب دستهٔ علمی/چشم‌انداز
- [ ] در هر دو زبان fa/en، RTL و LTR هر دو سالم (آینه‌ای)
- [ ] انیمیشن‌ها: فقط ورود reveal + هورتون/NDVI؛ حذف حرکت‌های تکراری مزاحم
