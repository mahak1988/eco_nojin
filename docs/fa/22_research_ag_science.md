## بخش ۱ — شبیه‌سازها و هسته‌های علمی

### ۱.۱ مدل‌های محصول (Crop Models)

| مدل | تمرکز | ویژگی کلیدی |
|---|---|---|
| DSSAT/CERES | فیزیولوژی گیاه (روزانه) | فنولوژی، رشد، نیتروژن؛ کالیبراسیون ژنوتیپ |
| APSIM | سامانه زراعی | خاک-گیاه-اقلیم-مدیریت؛ ماژولار |
| AquaCrop (FAO) | پاسخ عملکرد به آب | سادگی+دقت؛ آب‌محور |
| WOFOST | رشد محصول | توازن کربن؛ اروپایی |
| EPIC | بلندمدت | فرسایش+عملکرد+مدیریت |

**معادله محوری AquaCrop:** بیومس متناسب با تجمع تعرق است:
```
B = WP × ΣTr        (B: بیومس، WP: بهره‌وری آب نرمال‌شده، Tr: تعرق روزانه)
Y = B × HI          (Y: عملکرد، HI: شاخص برداشت)
```
(منبع: FAO openknowledge cb7392en؛ Steduto et al. 2009, Agron. J.)

### ۱.۲ مدل‌های هیدرولوژی
- **SWAT:** حوضه‌ای، پیوسته، روزانه — برای برنامه‌ریزی آبخیز
- **HEC-HMS:** بارش-رواناب، هیدروگراف — طراحی سیلاب
- **MIKE SHE:** فیزیکی-توزیعی (آب زیرزمینی+سطحی)
- **HBV:** مفهومی ساده، سریع

### ۱.۳ مدل‌های خاک، کربن و فرسایش
- **HYDRUS-1D:** جریان آب و املاح در خاک (معادله ریچاردز)
- **Century / RothC:** دینامیک کربن آلی خاک (دهه‌ها)
- **RUSLE/USLE:** فرسایش سالانه خاک

### ۱.۴ معادلات کلیدی (فرم متنی)

**تبخیر-تعرق مرجع FAO-56 (Penman-Monteith):**
```
ET0 = (0.408·Δ·(Rn−G) + γ·(900/(T+273))·u2·(es−ea)) / (Δ + γ·(1+0.34·u2))
Δ: شیب منحنی فشار بخار، Rn: تابش خالص، G: شار گرمای خاک،
γ: ثابت سایکرومتری، u2: سرعت باد در ۲ متر، (es−ea): کسر فشار بخار
```

**Hargreaves-Samani (داده کم):**
```
ET0 = 0.0023·(Tmean+17.8)·(Tmax−Tmin)^0.5·Ra
```

**ریچاردز (جریان آب خاک):**
```
∂θ/∂t = ∂/∂z [ K(θ)·(∂h/∂z + 1) ]
θ: رطوبت حجمی، h: فشار مکش، K(θ): هدایت هیدرولیکی
```

**SCS-CN (رواناب):**
```
Q = (P − Ia)² / (P − Ia + S)      Ia = 0.2·S
S = 25400/CN − 254  (میلی‌متر)
Q: رواناب، P: بارش، Ia: تلفات اولیه، S: نگهداشت بالقوه، CN: منحنی شماره
```
(منبع: HEC-HMS SCS CN Loss Model؛ مقادیر CN بر اساس کاربری/پوشش/گروه خاک A–D)

**Saint-Venant (جریان کانال/سیل):**
```
∂A/∂t + ∂Q/∂x = q
∂Q/∂t + ∂(Q²/A)/∂x + g·A·∂h/∂x = g·A·(S0 − Sf)
```

**RUSLE (فرسایش):**
```
A = R · K · LS · C · P
R: فرسایندگی باران، K: فرسایش‌پذیری خاک، LS: شیب/طول دامنه،
C: پوشش گیاهی، P: عملیات حفاظتی
```

### ۱.۵ روش‌های عددی و کدنویسی
- **تفاضل محدود / حجم محدود** برای گسسته‌سازی PDEها
- **رانگ-کوتا مرتبه ۴ (RK4)** برای ODEها
- **نیوتن-رافسون** برای معادلات غیرخطی (حلگرهای ضمنی)
- **پایداری:** شرط کورانت (CFL) — گام زمانی باید از نسبت سرعت×Δt/Δx محدودتر باشد
- **وکتوریزه‌سازی:** NumPy/Numba برای آرایه‌ها؛ هسته داغ به C++ با pybind11
- **الگوی معماری:** interface + registry + service layer؛ مدل‌ها به‌صورت
  plugin ثبت می‌شوند (align با معماری فعلی `engine/hydroma`)

### ۱.۶ کالیبراسیون و اعتبارسنجی
- **شاخص‌ها:** NSE (نزدیک ۱)، RMSE، R²، KGE، PBIAS (±۱۰٪ عالی)
- **روش‌ها:** GLUE، PEST، کالیبراسیون بیزی؛ آنالیز حساسیت Morris/Sobol
- **عدم‌قطعیت:** Monte Carlo؛ **داده‌گسیخت:** Ensemble Kalman Filter (EnKF)
- **قاعده طلایی:** هر مدل با داده مستقل (split train/test) اعتبارسنجی شود؛
  هرگز داده شبیه‌سازیشده را به‌عنوان مشاهده واقعی معرفی نکن (قانون پروژه)

### ۱.۷ معماری سرویس
REST/OpenAPI برای APIها، قرارداد داده (data contracts) مشترک، اصول FAIR،
طراحی آفلاین-فیرست (همگام‌سازی دلتا) برای کاربران روستایی، و کش.

## بخش ۲ — کودهای زیستی، ترکیبات کود و اصلاح‌کننده‌های خاک

### ۲.۱ کودهای زیستی (Biofertilizers)
- **تثبیت نیتروژن:** ریزوبیوم (همزیست لگوم)، ازتوباکتر/آزوسپیریلیوم (آزادزی)
- **حل‌کننده فسفات (PSB):** Bacillus، Pseudomonas، Aspergillus
- **حل‌کننده پتاسیم (KSB):** سیلیکات‌باکترها
- **PGPR:** سیدروفور (جذب آهن)، IAA (ریشه‌زایی)، ACC-deaminase (مقاومت تنش)
- **میکوریزا (AMF):** توسعه ریشه و جذب آب/فسفر
- **سیانوباکترها:** تثبیت N در شالیزار
- **کمپوست، ورمی‌کمپوست، کود سبز**
- **حامل‌ها:** پیت/تورب، مایع، گرانول؛ ماندگاری محصول بستگی به حامل و دما دارد

### ۲.۲ شیمی و ساخت کودها
- **فرمول‌بندی NPK:** ترکیب اوره (46-0-0)، DAP (18-46-0)، MOP (0-0-60) برای
  رسیدن به نسبت هدف — مسئله اختلاط خطی (مثال: ۱۰۰ کیلوگرم 20-20-20)
- **هیدرولیز اوره:** اوره → آمونیوم → (نیتریفیکاسیون) → نیترات؛ مهارکننده‌های
  نیتریفیکاسیون (DCD، NBPT برای اوره‌آز) راندمان را بالا می‌برند
- **کندرهش:** پوشش گوگردی/پلیمری، کپسوله، اوره-فرمالدئید
- **ریز مغذی‌های کلاته:** EDTA (خاک‌های معمولی)، EDDHA (خاک آهکی/قلیایی،
  پایدارتر)، DTPA؛ کلات آمینواسید (جذب سریع)
- **کودآبیاری (Fertigation):** حلالیت کامل، تزریق متناسب با فاز رشد
- **کمپوست:** نسبت C/N ایده‌آل ~۲۵–۳۰:۱؛ محاسبه:
```
C/N = Σ(C_i × m_i) / Σ(N_i × m_i)   (i: هر ماده اولیه، m: جرم)
```

### ۲.۳ اصلاح‌کننده‌های خاک
- **بیوچار:** پایدارسازی کربن (صدها سال)، افزایش CEC و نگهداشت آب؛
  تولید با پیرولیز (۳۵۰–۷۰۰°C)؛ کمپوست مشترک با بیوچار اثر بهتری دارد
- **زئولیت (کلینوپتیلولیت):** نگهداشت NH4+ و آب
- **گچ (CaSO4):** اصلاح خاک‌های سدیمی (جایگزینی Na با Ca)
- **آهک:** اصلاح اسیدیته (نیاز = f(ECE خاک هدف، عمق، جرم مخصوص))
- **هیدروژل/ابرجاذب (SAP):** نگهداشت آب در خاک‌های شنی
- **گوگرد:** اسیدی‌کردن خاک‌های قلیایی + گوگرد اکسیدکننده‌های زیستی
- **نانواصلاح‌کننده‌ها:** نانو زئولیت، نانو Cu/Zn — توجه: اثربخشی میدانی
  هنوز در برخی موارد بحث‌برانگیز است

### ۲.۴ محاسبات کلیدی
```
نیاز کود N = (نیاز محصول − عرضه خاک) / راندمان مصرف (NUE)
NUE معمول: ۰.۳–۰.۵ (اوره سطحی کمتر، کودآبیاری بیشتر)
```
مدیریت دقیق تغذیه: **قانون 4R** (منبع، مقدار، زمان، مکان درست)؛ کاربرد نرخ
متغیر (VRA) با نقشه‌های نیاز.

### ۲.۵ بازار (جستجو شده در این جلسه)
بازار جهانی کود زیستی ۲۰۲۵: ~۲.۷–۳.۳ میلیارد دلار (منابع: Future Market
Insights؛ GlobeNewswire — تا ۱۱.۰۸ میلیارد دلار در ۲۰۳۵ با CAGR بالا)؛
بازار آمریکا ۸۲۷.۹ میلیون دلار (۲۰۲۵). چین: ۱۱,۳۵۸ محصول کود زیستی ثبت‌شده
(فوریه ۲۰۲۵).

## بخش ۳ — آبخیزداری و کشت‌های مقاوم

### ۳.۱ سازه‌های آبخیزداری
| سازه | هدف | ملاحظات |
|---|---|---|
| بند اصلاحی (سنگ‌چین/گابیون/بتنی) | کنترل شیب آبراهه، رسوب‌گیری | گابیون انعطاف‌پذیرتر |
| تراس (مخزنی/کنتوری) | کاهش شیب، ذخیره رطوبت | هزینه بالا |
| کانال کنتور/انحرافی | انتقال آب، نفوذ | طراحی با CN |
| نیم‌هلالی (Half-Moon/Banquette) | جمع‌آوری رواناب درختان | کم‌هزینه، مناسب دیم |
| بند گلی (Gully Plug) | تثبیت آبراهه‌های فرسایشی | پشت‌سرهم |
| آبراهه چمنی | تخلیه ایمن آب | پوشش دائمی |
| جمع‌آوری آب باران | پشت‌بام/سطحی/میکروکچمنت | ذخیره + نفوذ |
| حوضچه نفوذ / چاه تزریق | تغذیه سفره | اقلیم‌های خشک |

اثر بندهای اصلاحی: کاهش ضریب رواناب (مطالعه: Yuan et al. 2022 —
کاهش بیشتر در بارش‌های کوتاه‌مدت).

### ۳.۲ معادلات طراحی
```
Rational:  Q = C·I·A     (Q: دبی پیک m³/s، C: ضریب رواناب، I: شدت بارش، A: مساحت)
SCS-CN:    Q = (P−0.2S)²/(P+0.8S) ، S = 25400/CN − 254
```

### ۳.۳ کشت‌های مقاوم
- **مکانیسم‌های تحمل خشکی:** ریشه عمیق، کارایی مصرف آب، تنظیم اسمزی
- **شوری:** هالوفیت‌ها (کینوا، سالیکورنیا)، ارقام شورپسند گندم/جو
- **غوطه‌وری:** برنج SUB1 (تحمل سیلاب)
- **دما:** تحمل گرما در گندم/ذرت؛ ارقام محلی ایران (منطبق با اقلیم)

### ۳.۴ فناوری‌های اصلاح‌نبات
- **MAS:** انتخاب به کمک نشانگر؛ **GS:** انتخاب ژنومی (پیش‌بینی ارزش اصلاحی)
- **CRISPR/Cas9:** نمونه‌های واقعی — حذف ژن‌های 4CL و RVE7 در نخود برای
  تحمل خشکی (روش DNA-free)؛ ویرایش ژن‌های تحمل شوری (مرور Springer 2024)؛
  مرور جامع تنش‌های غیرزیستی (Frontiers Plant Sci. 2023)
- **Speed Breeding:** چند نسل در سال (گلخانه + نوردهی کنترل‌شده)
- **فنوتایپینگ پهپادی:** غربال‌گری سریع جمعیت‌ها
- **بیوفورتیفیکاسیون:** برنج طلایی (ویتامین A)
- **گیاهان خوش‌آتیه:** تِف، ارزن، سورگوم، آمارانت

### ۳.۵ سامانه‌های تاب‌آور
کشت مخلوط، تنوع‌بخشی، آگروفارستری، کشاورزی حفاظتی (بی‌خاک‌ورزی).

## بخش ۴ — پایش و فناوری‌های نوین (تکمیل از دانش استاندارد)

### ۴.۱ شاخص‌های ماهواره‌ای (فرمول‌ها)
```
NDVI = (NIR − R) / (NIR + R)                  (گیاه‌سنجی پایه)
EVI  = 2.5·(NIR − R) / (NIR + 6·R − 7.5·B + 1)  (مقاوم به آئروسل/خاک)
SAVI = (NIR − R)·(1+L) / (NIR + R + L)        (L=0.5 خاک متوسط)
NDWI = (G − NIR) / (G + NIR)                  (آب/رطوبت پوشش)
NBR  = (NIR − SWIR2) / (NIR + SWIR2)          (سوختگی/تنش شدید)
```
- **Sentinel-2:** ۱۰ متر، باندهای R/G/B/NIR/SWIR — منبع اصلی پروژه (CDSE)
- **Sentinel-1 (SAR):** رطوبت خاک و تشخیص سیل (مستقل از ابر)
- **SMAP:** رطوبت خاک؛ **SIF (OCO-2):** فلورسانس — فتوسنتز واقعی
- **شاخص‌های خشک‌سالی:** SPI (بارش)، SPEI (بارش+دما)، VCI/VHI (ترکیب
  سلامت پوشش و دما)، آنومالی NDVI
- **دسترسی داده:** Copernicus Data Space (CDSE) و استاندارد STAC — زیرساخت
  موجود پروژه

### ۴.۲ IoT و پهپاد
- سنسور رطوبت خاک: خازنی (ارزان)، TDR/FDR (دقیق)؛ ایستگاه هواشناسی
- پروتکل‌ها: MQTT (محلی)، LoRaWAN (برد بلند/کم‌مصرف)، NB-IoT (سلولی)
- پهپاد چندطیفی: نقشه NDVI با دقت سانتیمتری، تشخیص تنش زودهنگام

### ۴.۳ هوش مصنوعی
- پیش‌بینی عملکرد با ML (رندوم‌فارست/گرادیان‌بوستینگ/شبکه عصبی)
- تشخیص آفت/بیماری با CNN روی تصاویر برگ
- دستیار دانش RAG با LLM (موجود در پروژه) + پاسخ چندزبانه
- نقشه‌برداری دیجیتال خاک (DSM): ML + covariates (توپوگرافی، اقلیم،
  سنجش‌ازدور) برای تخمین خصوصیات خاک در نقاط بدون نمونه
- MRV کربن ماهواره‌ای و ردیابی زنجیره تأمین با بلاک‌چین (موجود)

## بخش ۵ — نقشه راه اجرایی HyDroMa (گزارش research-d)

مراحل پیشنهادی زیرعامل (HP = آیتم کاری):

**فاز ۱ — حفاظت خاک و آب:**
- HP-WH-01..05: ماژول‌های سازه آبخیز (انتخاب نوع سازه، طراحی با SCS-CN،
  برآورد هزینه)
- HP-SL-01: مدل فرسایش (RUSLE با فاکتور C از NDVI)؛ HP-SL-03: نقشه حساسیت

- HP-VG-01/02: ماژول پوشش گیاهی (NDVI/LAI)

**فاز ۲ — مدل‌سازی تلفیقی:** SWAT+ برای حوضه؛ RUSLE؛ RothC برای کربن؛
AquaCrop/WEAP/HEC-RAS برای آب و محصول

**فاز ۳ — هشدار زودهنگام و اقدام پیش‌دستانه (Anticipatory Action):**
شاخص‌های خشک‌سالی، سامانه هشدار، توصیه‌های واکنشی

**فاز ۴ — داشبوردها و نقشه‌ها:** نقشه‌های تعاملی، داشبورد کشاورز/مدیر

**فاز ۵–۶ — پایش پیوسته و مقیاس‌پذیری:** داده‌گسیخت، API عمومی، چندزبانه
