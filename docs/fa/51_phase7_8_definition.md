# ۵۱. تعریف فاز ۷ و ۸ — نقشه اجرایی جدید

> وضعیت: تأییدشده | این سند محدوده فازهای ۷ و ۸ را تعریف میکند (ادامه فاز ۶ که کامل شد).

## فاز ۷ — ممیزی کربن و بازار اعتبار (MRV سطح ۲)
هدف: تبدیل دادههای تأییدشده به **اعتبار کربن واقعی و قابل پیگیری** در پلتفرم.
1. **جریان ممیزی:** ثبت validator (ادمین) ← رأیگیری `validation_votes` توسط auditor (تابع `auditor_vote` با بررسی نقش) ← وضعیت پروژه/اعتبار.
2. **صدور اعتبار کربن:** تابع `admin_issue_credits` (SECURITY DEFINER + بررسی ادمین) → درج در `platform_carbon_credits` + افزایش `credits_issued` + ثبت در `token_transactions`.
3. **گواهی اعتبار PDF** (فارسی RTL با fpdf2 — همان ماشین MRV): شناسه اعتبار، پروژه، مساحت، مقدار tCO2e، استاندارد، تاریخ، QR-less اما با کد اعتبارسنجی.
4. **داشبورد ادمین:** صف ممیزی (`verification_queue`)، رأیها، اعتبارهای صادرشده.
5. **فرانت:** کارت ممیزی (صف + فرم رأی + صدور اعتبار + دانلود گواهی) با دسترسی نقشمحور.

معیار پذیرش: auditor رأی دهد ← ادمین اعتبار صادر کند ← گواهی PDF فارسی با کد یکتا دانلود شود ← تراکنش در token_transactions ثبت شود.

## فاز ۸ — مقیاس بینالمللی و استقرار
هدف: آمادهسازی برای مصرفکنندگان جهانی (NGO/دولت/بازار کربن).
1. **همراستایی استانداردها:** صفحات ISO 14064، SDG، FAO Digital Villages، OGC.
2. **API استاندارد مکانی:** سرویس GeoJSON مبتنی بر PostGIS (معادل WFS-lite) + OpenAPI مستند (ReDoc).
3. **دوزبانه (FA/EN):** ساختار i18n برای صفحات عمومی.
4. **استقرار رایگان:** فرانت روی Vercel، بکاند روی Render/Railway (هر دو پلن رایگان) + متغیرهای محیطی امن.
5. **پورتال توسعهدهنده:** مستند API + مثالهای curl + وضعیت سرویسها.

معیار پذیرش: خروجی GeoJSON استاندارد از دیتابیس واقعی، دموی دوزبانه، لینک استقرار زنده.
