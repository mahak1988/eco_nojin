# ۰۴. مدل داده

**وضعیت:** تأیید شده | **نسخه:** ۱.۰.۰ | **زبان:** فارسی

## ۱. راهبرد ذخیره‌سازی

- **حالت پژوهشی:** SQLite (`hydroma_research.db`) از طریق SQLAlchemy؛ DuckDB برای پرس‌وجوهای تحلیلی سری زمانی برنامه‌ریزی شده.
- **تولید (برنامه‌ریزی‌شده):** PostgreSQL + PostGIS (docker-compose از قبل `postgis/postgis:16-3.4` دارد)؛ GeoPackage برای هندسه‌های مزرعه.

## ۳. موجودیت‌های بازارچه (درون‌حافظه‌ای، `engine/hydroma/marketplace/models.py`)

- **محصول:** دسته، قیمت هر کیلو، موجودی، حداقل سفارش، پرچم ارگانیک، ردپای کربن/آب، تاریخ برداشت، شماره بچ، کد ردیابی.
- **تولیدکننده:** نوع (تعاونی / عشایری / فردی)، وضعیت تأیید، امتیاز، گواهی‌ها (ارگانیک، GlobalG.A.P.، محصول عشایری و…).
- **سفارش:** چرخه در انتظار ← تأیید ← ارسال ← تحویل (یا لغو با بازگرداندن موجودی)؛ آمار درآمد.

همه وضعیت بازارچه برای حالت پژوهشی درون‌حافظه‌ای است؛ ماندگارسازی برنامه‌ریزی شده.

## ۴. پروژه‌های کربن (درون‌حافظه‌ای، `engine/hydroma/carbon/calculator.py`)

- **CarbonProject:** نوع (جنگل‌کاری، جنگل‌کاری مجدد، کربن خاک، بیوچار، آگروفارستری، احیای مرتع)، مساحت، مدت، مکان، وضعیت (پیش‌نویس ← ثبت ← تأیید)، تأییدکننده، تن تخمینی، متدولوژی.

## ۵. لاگ همگام‌سازی (`services/api_gateway/routers/sync.py`)

فهرست درون‌حافظه‌ای `{device_id, client_id, endpoint, method, payload, timestamp, server_id, synced_at}` — عملیات آفلاین صف‌شده کلاینت‌های موبایل. ماندگاری و حل تعارض برنامه‌ریزی شده.

## ۶. داده ماهواره و اقلیم

- **NASA POWER** سری زمانی هواشناسی (T2M_MIN/MAX، RH2M، WS2M، ALLSKY_SFC_SW_DWN، PRECTOTCORR) — دریافت زنده.
- **Sentinel-2 L2A** از طریق STAC عمومی Element 84 — فراداده واقعی، **مقادیر باندها فعلاً شبیه‌سازی‌شده** (رجوع: `02_hydroma_engine.md` بخش ۷).
- رسترهای خام (GeoTIFF/NetCDF) زیر `data/raw/` (در git نادیده گرفته شده).

## ۷. مهاجرت شِما

حالت پژوهشی در شروع از `Base.metadata.create_all` استفاده می‌کند. تولید نیازمند مهاجرت Alembic است؛ راه‌اندازی Alembic کار برنامه‌ریزی‌شده است.

## ۸. موجودیت‌های آینده

چاه‌های آب زیرزمینی، برنامه‌های آبیاری، سوابق دام/گله، اندازه‌گیری‌های MRV، توکن‌های پاداش، فهرست اکوتوریسم، قراردادهای بیمه شاخص‌محور.
