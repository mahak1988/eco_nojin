# Conversation Summary

This document preserves the agreed direction of the Eco Nojin / HyDroMa project.

## Project Names

- Engine: HyDroMa
- Platform: Eco Nojin

## Core Agreement

- Build a modular, standards-based, international platform.
- Use Python for orchestration, AI, data, and API layers.
- Use C++ for the high-performance scientific computation core.
- Use TypeScript for the frontend and dashboards.
- Start with documentation, then proceed module by module.
- Keep code and code comments in English.
- Keep documentation bilingual: English and Persian.
- Support internationalization from the first step.

## Functional Scope

The platform must support:

- Agriculture, rangeland, livestock, and rural livelihoods.
- Hydrology, groundwater, flood, runoff, and watershed management.
- Soil, erosion, biofertilizers, compost, biochar, and soil restoration.
- Climate monitoring, drought, vegetation, and topography.
- Crop growth, irrigation, planting recommendation, and scenario planning.
- Risk management, crisis management, and resilience.
- Ecosystem restoration, afforestation, and desertification control.
- Carbon sequestration, MRV, rewards, and tokenized incentives.
- Accounting, finance, warehouse, marketplace, and ecotourism.
- Knowledge assistant, search, machine learning, and AI advisory.

## Target Users

- Smallholder farmers
- Pastoralists and nomads
- Rural youth seeking employment
- Rural women
- Cooperatives
- NGOs and government agencies
- Buyers and impact investors

## International Standards Direction

The platform should align with standards and frameworks from:

- FAO
- IFAD
- World Bank
- WMO
- ISO
- OGC
- UN SDGs
- GODAN
- Global carbon and environmental reporting frameworks

## Memory Rule

Future development must remain aligned with this document.
Any major change must be recorded as a new decision.
