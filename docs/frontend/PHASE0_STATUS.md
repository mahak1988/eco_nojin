# گزارش وضعیت فاز ۰ — پایهٔ فرانتاند واقعی (۲۰۲۶/۰۹/۲۲)

> این سند وضعیت اجراشدهٔ فاز ۰ برنامهٔ جامع (نسخهٔ ۲٫۰) را ثبت میکند و مبنای ادامهٔ کار است.

## ۱) آنچه اجرا شد

| مورد | وضعیت |
|---|---|
| پشتهٔ جدید `apps/web` | Next.js 15.5 (App Router) + React 19.3 + TypeScript strict + Tailwind CSS 4 |
| انتخابگر ۱۴ زبان | fa، en، ar، ur، de، es، fr، hi، it، ms، pt، ru، zh، bn — مسیر پیشوندی `/{locale}/…` |
| fallback زنجیرهای | هر زبان → fa؛ زبانهای بدون کاتالوگ کامل برچسب «ترجمهٔ ماشینی» میگیرند |
| RTL/LTR | `dir` پویا روی `<html>` برای fa/ar/ur؛ اعداد و داده با کلاس `num` همیشه LTR و isolate |
| توکنهای طراحی | پالت oklch «زمینِ زنده» (آب/سبز/خاک/مس) در `@theme` تیلویند ۴ |
| لایهٔ API واقعی | `src/lib/api/client.ts` — فقط `apiGet` به دروازهٔ واقعی؛ **هیچ لایهٔ mock وجود ندارد** |
| پروکسی API | rewrite سمت سرور `/api/:path*` → `API_PROXY_TARGET` (بدون مشکل CORS) |
| رندر | `dynamic = 'force-dynamic'` — هر درخواست از بکاند زنده میخواند؛ هیچ پیشرندر با دادهٔ کهنه |

## ۲) سیاست «فقط دادهٔ واقعی» چگونه اعمال شد

1. کلاینت API تنها راه دریافت داده است؛ صفحات از مسیرهای واقعی `/api/v1/...` میخوانند.
2. عدم قطعیت صادقانه: شکست endpoint → نمایش کد خطا و پیام «دردسترس نیست» (بدون مقدار جایگزین).
3. دیتابیس خالی → شمارندهها صفر نمایش داده میشوند و برچسب صریح دارد؛ هیچ دادهٔ نمونه/آزمایشی تولید نمیشود.
4. زبان بدون کاتالوگ کامل → متن fallback فارسی + برچسب «ترجمهٔ ماشینی».

## ۳) نقاط اتصال واقعی (فعلاً)

| Endpoint | مصرفکننده | وضعیت آزمایش زنده |
|---|---|---|
| `/api/v1/platform/stats` | کاور (شمار پروژه/بازارچه) | 200 — واقعی: ۰/۰ |
| `/api/v1/platform/health` | صفحهٔ وضعیت | 200 — operational، supabase ✓، C++ ✓ |
| `/api/v1/platform/landscapes` | صفحهٔ وضعیت (آزمون سلامت) | **500 — باگ واقعی بکاند: getaddrinfo failed** (ثبت شد، باید در سرویس رفع شود) |

## ۴) شواهد کیفیت

- `pnpm build` سبز: ۳۱ مسیر، همگی Dynamic؛ First Load JS ≈ **107KB** (زیر بودجهٔ 200KB).
- آزمایش زندهٔ production: `/fa`، `/en`، `/ar`، `/zh`، `/fa/status` همه 200.
- مقادیر نمایشدادهشده در کاور فارسی: «۰ بهرهبردار، ۰ بازارچهٔ فعال، پس از پایلوت» — از دیتابیس واقعی.

## ۵) گامهای بعدی فاز ۰

1. رفع باگ ۵۰۰ در سرویس `platform/landscapes` (نشانهای از مشکل DNS/آدرس خارجی در بکاند).
2. تولید کلاینت تایپشدهٔ کامل از `openapi_schema.json` (۴۴۵ مسیر) با Orval و اتصال `packages/types`.
3. انتقال داراییهای نسل ۲ (محتوای تایپشدهٔ fa/en، فونتهای محلی، sitemap/OG، تستها) به `packages/*`.
4. تکمیل کاتالوگهای ۱۲ زبان باقیمانده (موج ۰: fa/en کامل؛ سپس ar/ur/de/es/fr).
5. ساخت کیت پایه (۱۵ کامپوننت) و قالبهای T01–T12؛ سپس برش عمودی کامل (کاور + خانه + یک ابزار علمی + یک محصول).

## ۶) اجرا

```bash
# بکاند (دروازهٔ API)
.venv\Scripts\python -m uvicorn services.api_gateway.main:app --host 127.0.0.1 --port 8000

# فرانتاند
cd apps\web
pnpm install
pnpm dev        # http://localhost:3000/fa
```

متغیر محیطی: `API_BASE_URL` (سمت سرور) و `API_PROXY_TARGET` (پروکسی) — پیشفرض `http://127.0.0.1:8000`.
