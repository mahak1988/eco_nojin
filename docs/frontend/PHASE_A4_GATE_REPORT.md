## ۲) سه علت ریشه‌ای که پیدا شد

### علت ۱ — بیلد production شکسته بود (رفع شد)
```
./src/components/ui/Navigation.tsx
Error: You're importing a component that needs `useRef`. This React Hook only works in a
Client Component. To fix, mark the file (or its parent) with the "use client" directive.
```
فایل `apps/web/src/components/ui/Navigation.tsx` از `useRef` استفاده می‌کرد ولی `'use client'` نداشت و از یک Server Component (`design-system/components/page.tsx`) ایمپورت می‌شد.
**اصلاح:** افزودن `'use client';` در ابتدای فایل. نتیجه:
```
✓ Compiled successfully in 91s
✓ Generating static pages (13/13)   BUILD_EXIT=0
```
پشتیبان: `Navigation.tsx.bak-20260928`

> این علت توضیح می‌دهد چرا در `PAGE_GATES.md` نوشته شده «هیچ دروازه‌ای در برابر دروازهٔ زنده اجرا نشده»: گیت CI روی `next start` کار می‌کند و بیلد وجود نداشت.

### علت ۲ — در حالت `next dev` ناوبری کلاینتی کار نمی‌کند
با کاوشگر اختصاصی، کلیک روی CTA کاور در حالت dev:
```
environment  : {"onLine":true,"swController":null}
anchor href  : /fa/home
url after    : http://127.0.0.1:3111/fa        ← بدون تغییر
defaultPrevented: true                          ← هندلر Link مانع پیش‌فرض شد
framenavigated: /fa → /fa                        ← هیچ ناوبری‌ای رخ نداد
```
هیچ خطای JS، هیچ درخواست RSC، و پس از پاک‌کردن کامل `.next` هم تکرارشدنی.
**در حالت production (`next start`) همان کلیک:**
```
url after : http://127.0.0.1:3111/fa/home        ← ناوبری موفق
```
**نتیجه:** گیت باید در حالت **سرور بیلدشده** اجرا شود (همان کاری که `playwright.config.ts` با `CI=1` انجام می‌دهد). اجرای محلی با `next dev` نتایج کاذب تولید می‌کند.

### علت ۳ — پنج شکست باقی‌مانده: ابهام انتخابگر در اسپک‌ها
نمونهٔ خطای واقعی:
```
strict mode violation: locator('div').filter({ hasText: /^Land profiles$/ }) resolved to 3 elements
  1) <div class="text-sm text-ink-soft">Land profiles</div>
  2) <span class="chip">210 Land profiles</span>
  3) <h2 class="text-sm font-semibold text-ink-soft">Land profiles</h2>
```
یعنی صفحه **درست رندر می‌شود** (دادهٔ واقعی هم به ۲۱۰ پروفایل رسیده)، ولی اسپک انتظار یک عنصر یکتا دارد و حالا سه عنصر با همان متن وجود دارد.
**اصلاح لازم (سمت تست، نه اپ):** استفاده از `.first()` یا انتخابگر دقیق‌تر (نقش/سطح).
