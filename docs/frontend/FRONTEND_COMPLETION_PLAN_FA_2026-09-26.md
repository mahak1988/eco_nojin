## ۲) آنچه واقعاً «اتصال» یک سطح را می‌سازد

اتصال یعنی چهار چیز، نه فقط یک فایل `page.tsx`:

```
۱) قرارداد      endpoint در openapi.json وجود دارد
۲) تایپ         شکل پاسخ از روتور واقعی استخراج شده، نه حدس
۳) رندر         همه حالت‌ها: loading / empty / offline / unavailable / unauthorized
۴) ثبت          کاتالوگ مسیر را به فایل صفحه bind می‌کند و تست آن را تضمین می‌کند
```

اگر (۱) نباشد، سطح `unavailable` می‌ماند. اگر (۲) نباشد، فقط رندر عمومی ممکن است.

## ۳) کشف کلیدی: قراردادها فیلد اعلام نمی‌کنند

اندازه‌گیری روی `openapi.json`:

| شکل پاسخ | تعداد نمونه | نتیجه |
|---|---|---|
| `{}` (کاملاً خالی) | `/analytics/*`، `/marketplace/stats`، `/marketplace/producers` | هیچ فیلدی اعلام نشده |
| `additionalProperties: true` | `/manual/*`، `/content/search` | فقط «هرچیزی» |
| با پارامتر مسیر | `/manual/sites/{site_id}` | نوع ساختار نامعلوم |

**پیامد:** نوشتن `interface` با فیلدهای حدسی برای این مسیرها، جعل داده است. بنابراین یک لایه رندر مشترک ساخته شد که **شکل را از خود پاسخ می‌خواند**:

- `components/surface/ShapeView.tsx` — آبجکت → فهرست تعریف، آرایه رکورد → جدول با ستون‌های خود دیتاست، مقدار تهی → خط تیره
- `components/surface/EndpointSurface.tsx` — پوسته مشترک: عنوان، provenance، نام دقیق مسیر، همه حالت‌ها
- `lib/api/surfaces.ts` — تایپ پاسخ عمداً `unknown`

تا backend مدل پاسخ اعلام کند (B12)، این تنها راه صادقانه است. **این یک راه‌حل موقت است، نه راه‌حل نهایی** — در نقشه راه به‌عنوان بدهی فنی ثبت شده.

## ۷) دروازه‌های لازم برای بستن هر موج

```
pnpm --dir apps/web quality          # lint + format + tsc + vitest + i18n + site-url
pnpm --dir apps/web build            # build تولیدی
node scripts/check-verified-claims.mjs
$env:PLAYWRIGHT_CHANNEL='msedge'
pnpm --dir apps/web exec playwright test tests/{surfaces,manual,tier0,a11y,responsive}.spec.ts --project=chromium
```

**قواعد غیرقابل مذاکره:**
- صفحه‌ای که `live` اعلام می‌شود باید `routeFile` داشته باشد و تست کاتالوگ آن را تضمین کند.
- هیچ صفحه‌ای برای مسیر `unavailable` ساخته نمی‌شود.
- هیچ فیلد، واحد یا برچسبی که سرور نفرستاده افزوده نمی‌شود.
- هیچ صفحه نوشتنی حساسی پیش از بستن B1/B2/B3/B4 ساخته نمی‌شود.
- `git add .` ممنوع؛ فقط مسیرهای صریح.
