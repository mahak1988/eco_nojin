# S-SCI — قرارداد انطباق علمی

> هر فرمول علمی **دقیقاً یک محل تعریف** دارد، با مرجع و واحد. بقیه به آن ارجاع می‌دهند.

**کد مرجع:** `services/_contracts/formula.py`
**دروازه:** G6 (انطباق علمی اجباری) — فاز ۳

## چرا این استاندارد

سه فرمول LS و چهار فرمول K برای یک مدل:

| فرمول | نسخه مرجع | حذف‌شدنی |
|---|---|---|
| LS | Wischmeier & Smith (FAO RUSLELE) | ۴ پیاده‌سازی دیگر |
| K | EPIC با ضریب `0.1317` (Renard 1997) | ۳ پیاده‌سازی دیگر |
| R | Fournier 1961 (FAO) | ۱ مورد |
| SCS-CN | USDA TR-55 | ۱ مورد |
| کلاس فرسایش | آستانه ۵/۱۲/۲۵/۵۰ (FAO) | ۱ مورد با آستانه ۵/۱۰/۲۰ |

دو نسخه EPIC تا **۷٫۶ برابر** اختلاف داشتند، چون یکی ضریب `0.1317` را اعمال می‌کرد و دیگری نه — و واحد SOC متفاوت می‌خواستند (g/kg در برابر درصد) بدون هیچ نگهبان نوعی.

## قواعد سخت

1. **هر فرمول دقیقاً یک محل تعریف دارد** — `services/_contracts/formula.py`، با `register()`.
2. **هر فرمول `reference` دارد.** `register()` مرجع خالی را رد می‌کند. عدد بدون منبع، قابل ردیابی نیست.
3. **هر موتور علمی حداقل یک آزمون انطباع عددی دارد.** الگو: `tests/integration/test_models_phase7.py`.
4. **هر موتور `MotorType` صحیح گزارش می‌دهد.** الگو: `services/simulation/base.py`.
5. **نسخه «واقعی» یا به مسیر درخواست می‌آید یا صریحاً `NOT_IMPLEMENTED` اعلام می‌کند.** وضعیت سوم — پنهان بودن — ممنوع.
6. **آستانه‌های طبقه‌بندی یکی است.** همان فیلد نباید بسته به خط لوله متفاوت طبقه‌بندی شود.

## واحدها — دلیل اصلی ریشه‌ها

| کمیت | واحد | دام موجود |
|---|---|---|
| SOC برای K | **g/kg** | نسخه `soil_fetcher` درصد می‌خواست |
| شیب برای LS | **درجه** | `chain_runner` درصد شیب بدون تریگونومتری می‌گرفت |
| K | `t·ha·yr·mm` | یک نسخه بازه `0.15–0.45` می‌داد، خارج از محدوده استاندارد |
| CN | عدد ۳۰ تا ۱۰۰ | — |

## درست / نادرست

```python
# ✅ درست
from services._contracts.formula import ls_factor, k_factor_epic
ls = ls_factor(slope_deg)                     # درجه
k  = k_factor_epic(soc_g_per_kg, clay, silt)  # g/kg

# ❌ نادرست — فرمول چهارم LS
ls = 0.065 + 0.045*slope_pct + 0.0065*slope_pct**2

# ❌ نادرست — نسخه EPIC بدون 0.1317، واحد متفاوت
k = 0.2 + 0.3*soc_frac**2 + 0.025*(clay + silt)   # تا ۷٫۶ برابر خطا
```

## وضعیت پوشش

`services/scientific_motors/` با ~۸٬۶۰۰ خط و ۳۰+ کلاس **صفر آزمون عددی** دارد. تنها ارجاع موجود `tests/unit/test_rusle_uncorrelated.py` است که `chain_runner.py` را **به‌صورت متن منبع** پارس می‌کند — نه آزمون محاسبه.

افزودن آزمون انطباع عددی برای این بسته، مهم‌ترین شکاف باز و در فاز ۴ بلوک ۲ قرار دارد.
