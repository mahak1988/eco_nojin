۰مقدمه و بیانیه یکپارچگی

اکو نوژین (Eco Nojin) هسته علمی و موتور حکمرانی AI است. هیدروما (HYDROMA) پلتفرم کسب‌وکار و بازارگاه چندطرفه است. این سند، مرزها، اتصالات و برنامه ۹۰ روزه یکپارچه را تعریف می‌کند.

اصل طلایی یکپارچگی: هیچ‌گاه لایه کسب‌وکار (هیدروما) مستقیماً معادلات علمی (اکو نوژین) را تغییر نمی‌دهد. تمام تمیمات علمی از طریق EngineGateway و Tasmimyar با شواهد و provenance عبور می‌کنند.

ساختار سه‌لایه یکپارچه

لایه نام فناوری نقش

۲ Gateway + Tasmimyar + Daneshyar Python، REST Adapter، SQLite (cache) ترجمه درخواست تجاری به زبان علمی، تصمیم‌گیری مبتنی بر شواهد

قواعد معماری (AR-01 تا AR-10)

  1. AR-01 Separation of Concerns: هیچ ماژول علمی مستیماً به اینترنت متصل نمی‌شود.
  2. AR-02 Dependency Inversion: هسته علمی به abstraction (Port) وابسته است، نه implementation.
  3. AR-03 Model Immutability: معادلات علمی ثبت‌شده در Model Card تغییرناپذیرند.
  4. AR-04 API Stability: تغییر API عمومی = STOP (SB-03).
  5. AR-05 Evidence-Based Decision: هر تصمیم Tasmimyar باید شاهد (Evidence) داشته باشد.
  6. AR-06 Unit Safety: تمام محاسبات با pint/UnitRegistry.
  7. AR-07 AI Guardrails: AI حق تغییر معادله یا پارامتر علمی را ندارد.
  8. AR-08 Fail Closed: در عدم قطعیت، سیستم متوقف می‌شود.
  9. AR-09 Provenance Traceability: هر خروجی باید منشأ خود را تا داده خام بازگو کند.
  10. AR-10 Testable Architecture: هر قاعده معماری باید آزمون مثبت/منفی داشته باشد.

۲.۱ نقشه قابلیت‌ها (Capability Map)

هیدروما H0 — هسته مرکزی

  • مدیریت کاربران و سازمان‌ها (۱۰ گروه کاربری)
  • مدیریت دسترسی مبتنی بر نقش (RBAC)
  • داده‌های پایه: محصول، واحد، منطقه، خدمت
  • موتور قواعد و گردش کار (Workflow Engine)
  • Audit Log کامل (چه کسی، چه زمانی، چه تغییری)

اکو نوژین — هسته علمی

  • ۱۸ مدل علمی تأییدشده (سطح ۳)
  • Model Registry با ۷۰ مدل
  • Scientific Validation Register (S18)
  • Unit Registry (pint)
  • Local Data Mirror (CHIRPS, ERA5, SoilGrids)

هیدروما H1 — بازار هوشمند

  • ثبت عرضه و تقاضا
  • موتور تطبیق (Matching Engine)
  • مدیریت سفارش و قرارداد
  • محاسبه کارمزد و تسویه

اکو نوژین — Tasmimyar

  • وزن‌دهی چندمعیاره (MCDM)
  • آستانه RECOMMEND ≥ ۰.۷
  • آستانه CAUTION ≥ ۰.۴
  • Sensitivity Analysis (Pareto Consistency)

هیدروما H2 — رادار بازار

  • تحلیل تغییرات قیمت
  • شناسایی روندهای فصلی
  • هشدار ریسک تأمین
  • پیش‌بینی تقاضا

اکو نوژین — Daneshyar

  • Epistemic Status Management
  • Conflict Resolver
  • Claim-Evidence Linking
  • Knowledge Graph

هیدروما H5 — هماهنگ‌کننده منابع

  • ماشین‌آلات، حمل، انبار، سردخانه
  • تطبیق سفارش با ظرفیت
  • رتبه‌بندی بر اساس هزینه و فاصله
  • رزرو و پیگیری

اکو نوژین — شاخص‌های نوین

  • FDII (Flash Drought Intensity Index)
  • CDHE (Compound Drought-Heat Index)
  • CMSI (Crop Multi-Stress Index)
  • WSNI, RRI, IWEq
