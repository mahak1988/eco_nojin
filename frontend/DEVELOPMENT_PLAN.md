## معماری محتوا

- **SSOT:** `src/content/sections/*.ts` (۲۳ فایل، دو زبانه fa/en)
- **جمع‌آوری مجدد:** `src/content/site.ts` (بارل خودکار، `content: Record<Lang, SiteContent>`)
- **توزیع:** هوک `useLang()` در `LanguageContext.tsx` → `t: SiteContent` به همه کامپوننت‌ها
- **منوها:** `src/content/menus.ts` (گروه‌های فوتر، لینک‌های قانونی) — جدا از محتوای بخش‌ها
- **محتوای سطح صفحه:** `src/content/pages/*.ts` (developers, investors, partners و ...)

## معیار تأیید

```sh
cd frontend
npx tsc --noEmit  # انتظار صفر خطا
npx vite build     # انتظار ساخت موفقیت‌آمیز
```

## تصمیمات معلوق (مسدودکننده P2/P3)

1. SLA پاسخ به تماس‌ها (۲۴ ساعت؟)
2. انتشار عمومی خلاصه INVESTOR_PITCH (با مجوز)
3. شروع پایلوت → فعال‌سازی شمارنده‌های زنده
